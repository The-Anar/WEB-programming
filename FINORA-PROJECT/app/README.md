## Features
1. **Dashboard:** Real-time summary of Total Balance, Monthly Income, Expenses, Savings, 6-month Cash Flow line chart, and Category Doughnut breakdown.
2. **Transactions:** Add, delete, search, and filter income/expense records in Korean Won (`₩`).
3. **Budgets:** Monthly category limits with automatic progress tracking.
4. **Analytics & Savings Goals:** Savings rate metrics and interactive goal contributions persisted via `localStorage`.

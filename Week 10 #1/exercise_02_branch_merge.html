Exercise 02 — Branch & Merge

Practice creating a feature branch, making separate commits, switching branches, and merging your completed work into main.

BATSUREN ANAR · STUDENT ID: 202637018

Exercise Overview

In this exercise, you will simulate a real development task. You already have a simple website, and now you need to add a new About section without directly editing the main branch.

Objective

Understand how branches isolate development and how merging combines completed changes.

Tools

VS Code, a terminal, Git, and a local project folder.

Final Result

A main branch containing the changes developed and committed on a feature branch.

Part 01 — Prepare Your Repository

TASK 01

Open an existing Git project that has at least one commit on its main branch.

Check your current branch and repository status: 

git branch
git status

If you do not have a project yet, create a new folder and initialize Git: 

mkdir branch-practice
cd branch-practice
git init

Create an index.html file and add a simple homepage: 

<!doctype html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <title>Branch Practice</title>
</head>
<body>
    <h1>My Website</h1>
    <p>Welcome to my project.</p>
</body>
</html>

Save and create the starting commit: 

git add index.html
git commit -m "Create initial homepage"

Part 02 — Create a Feature Branch

TASK 02

Create a new branch named feature/about. 

git checkout -b feature/about

This command creates the branch and switches your working directory to it.

Check the branches: 

git branch

The asterisk should appear next to feature/about.

Part 03 — Add an About Section

TASK 03

Open index.html and add an About section inside the body. 

<section>
    <h2>About Me</h2>
    <p>I am a student learning web development.</p>
</section>

Save the file. Then check the changes: 

git status
git diff

Git should show the new lines added to your file.

Part 04 — Commit the Feature

TASK 04

Stage and commit your new About section. 

git add index.html
git commit -m "Add about section"

Your feature branch now contains a commit that does not yet exist on main.

Check the commit history: 

git log --oneline

Part 05 — Switch Back to Main

TASK 05

Return to the main branch: 

git checkout main

Open index.html again. You should see the original homepage without the About section.

The changes were committed on feature/about, so main has not received them yet.

Part 06 — Merge the Feature Branch

TASK 06

While you are on main, merge the feature branch: 

git merge feature/about

Git combines the changes from feature/about into the current branch.

Check the Result

git status
git log --oneline

Open index.html. The About section should now be part of main.

Part 07 — Delete the Completed Feature Branch

TASK 07

After successfully merging the feature, you can delete the old branch if you no longer need it. 

git branch -d feature/about

Check the remaining branches: 

git branch

The merged changes remain in main. Deleting the branch name does not undo the merge.

Complete Command Sequence

Here is the full workflow in order: 

# Create a feature branch
git checkout -b feature/about

# Edit index.html

# Stage and commit changes
git add index.html
git commit -m "Add about section"

# Return to main
git checkout main

# Merge the feature
git merge feature/about

# Delete the merged branch
git branch -d feature/about

# Review the history
git log --oneline

Part 08 — Understand the Final Result

Before merging, the About section existed only on the feature branch.

After merging, main contains the new section too.

Before Merge

main
  └── Initial homepage

feature/about
  └── Initial homepage
      └── Add about section

After Merge

main
  └── Initial homepage
      └── Add about section

Knowledge Check

1. Which command creates and switches to a new branch?

2. What should you do before merging feature/about into main?

3. What does git merge feature/about do when you are on main?

4. What happens when you delete a branch after merging it?

Exercise Summary

  • Branches allow independent development.
  • git checkout -b creates and switches to a branch.
  • Commit your feature changes before merging.
  • Switch to the target branch before merging.
  • git merge combines branch changes.
  • git branch -d deletes a merged branch.

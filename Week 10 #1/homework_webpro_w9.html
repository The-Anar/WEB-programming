What I Ran

The following commands initialize the repository, configure my Git identity, create a commit, connect GitHub, and push the project. 

git init -b main

git config user.name "Batsuren Anar"
git config user.email "YOUR-GITHUB-EMAIL"

git add index.html

git commit -m "Add homepage with name and date for Week 9 homework"

git remote add origin https://github.com/The-Anar/webpro-w9.git

git push -u origin main

Replace YOUR-GITHUB-EMAIL with the email address you use for your Git commits.

GitHub Pages Configuration

After pushing the repository, I enable GitHub Pages using the following settings: 

GitHub Repository Settings

Pages
    Source: Deploy from a branch

    Branch: main
    Folder: / (root)

GitHub Pages publishes the index.html file from the root directory of the main branch.

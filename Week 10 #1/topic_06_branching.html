Topic 06 — Branching

Learn how Git branches let you develop new features, experiment safely, and merge completed work into your main project.

What Is a Git Branch?

A branch is an independent line of development in a Git repository. It allows you to work on a feature or fix without directly changing the main branch.

For example, you can create a new branch to build a search feature while the main version of your website remains unchanged.

Example project branches:

  • main — the main project version.
  • feature/search — a new search feature.
  • feature/login — a login feature.
  • fix/navigation — a navigation bug fix.

Why Use Branches?

01. Safe Development

Develop new features without directly changing the main project version.

02. Experimentation

Test ideas and try different solutions without affecting other work.

03. Team Collaboration

Different developers can work on different features at the same time.

Understanding Branch Structure

A branch starts from an existing commit. New commits can then be added to that branch independently.

main
feature

Conceptual illustration: the feature branch can receive its own commits while the main branch continues separately.

01. Create and Switch to a Branch

Use git checkout -b to create a new branch and immediately switch to it. 

git checkout -b feature/search

This command performs two actions:

  1. Creates a branch named feature/search.
  2. Switches your working directory to that branch.

02. List Existing Branches

Use git branch to see the local branches in your repository. 

git branch

Example Output

  feature/search
* main

The asterisk * indicates the branch you are currently using.

03. Switch Between Branches

Use git checkout followed by the branch name to switch to an existing branch. 

git checkout main

This switches your working directory to the main branch.

Alternative Modern Command

git switch main

git switch is a modern command designed specifically for switching branches.

04. Merge a Branch

After completing your feature, you can merge its changes into another branch. 

# Switch to the branch receiving the changes
git checkout main

# Merge the feature branch into main
git merge feature/search

The merge command combines the changes from feature/search into the currently checked-out branch.

You normally switch to the target branch before running the merge command.

Complete Branching Example

Imagine you are adding a search box to your portfolio website. 

# Create a new feature branch
git checkout -b feature/search

# Edit your project files

# Stage the changes
git add .

# Commit the feature
git commit -m "Add search feature"

# Return to the main branch
git checkout main

# Merge the feature into main
git merge feature/search

Your search feature is now included in the main branch after a successful merge.

Common Branch Commands

# List branches
git branch

# Create and switch to a new branch
git checkout -b feature/login

# Switch to an existing branch
git checkout main

# Merge another branch into the current branch
git merge feature/login

# Delete a branch after merging
git branch -d feature/login

Delete a branch only when you no longer need it. The -d option normally prevents deleting an unmerged branch.

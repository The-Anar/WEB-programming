Topic 07 — Remote, Push & Pull

Learn how to connect a local Git repository to GitHub, upload your commits, and download updates from a remote repository.

What Is a Remote Repository?

A remote repository is a version of your Git project stored on another computer or online service. GitHub is a popular service for hosting remote repositories.

Your local repository is stored on your own computer. Your remote repository can be accessed online, allowing you to share your work and collaborate.

Three Important Git Commands

01. git push

Uploads your local commits to a remote repository. 

git push

02. git pull

Downloads remote changes and integrates them into your current local branch. 

git pull

03. git clone

Creates a local copy of an existing remote repository. 

git clone URL

01. Connect Your Local Repository to GitHub

First, create a repository on GitHub. Then connect your local repository to it using git remote add. 

git remote add origin https://github.com/username/portfolio.git

What does this command mean?

  • git remote manages remote repository connections.
  • add adds a new remote connection.
  • origin is the conventional name for the remote.
  • The URL identifies your GitHub repository.

Replace the example URL with the actual URL of your own GitHub repository.

02. Upload Your Commits with git push

After connecting your local repository to GitHub, use git push to upload your commits. 

git push -u origin main

Command explanation:

  • push uploads local commits.
  • -u sets the upstream tracking relationship.
  • origin is the remote repository name.
  • main is the branch being pushed.

After the upstream is configured, you can usually use the shorter command: 

git push

03. Download Updates with git pull

When another person uploads new commits to GitHub, your local repository does not automatically receive them.

Use git pull to download and integrate those remote changes into your current branch. 

git pull origin main

This command gets updates from the remote origin, branch main, and integrates them into your current local branch.

Before pulling, make sure you are on the branch you want to update.

04. Copy a Repository with git clone

If you want to start working on an existing GitHub project, you can clone it to your computer. 

git clone https://github.com/username/portfolio.git

Git creates a local copy of the repository, including its project files and Git history.

A remote named origin is normally configured automatically when you clone a repository.

Complete Example: Upload a Portfolio

Imagine you have created a local portfolio project and want to publish its Git history on GitHub. 

# Create a local repository
git init

# Stage your project files
git add .

# Save a commit
git commit -m "Create portfolio homepage"

# Connect to your GitHub repository
git remote add origin https://github.com/username/portfolio.git

# Upload the main branch
git push -u origin main

Replace the sample URL with your own repository URL. Your local branch must be named main for this exact example.

Important: Local Commit vs GitHub Upload

A commit and a push are different actions.

git commit

Saves a snapshot of your staged changes in your local repository.

git push

Sends your local commits to the remote repository.

If you only commit your changes, they are saved locally. They are not automatically uploaded to GitHub.

WEEK 10.2 · EXERCISE 01

Enable GitHub Pages

Publish the Week 9 web programming repository using GitHub Pages.

BATSUREN ANAR · STUDENT ID: 202637018

01 · OBJECTIVE

Publish My Repository

In this exercise, I enable GitHub Pages for my webpro-w9 repository. GitHub Pages will publish the website so that it can be accessed through a public URL.

My GitHub repository

github.com/The-Anar/webpro-w9

02 · INSTRUCTIONS

Enable GitHub Pages

Step 1 — Open repository settings

Go to my GitHub repository and open Settings → Pages.

Open Pages Settings ↗
Step 2 — Select the publishing source

Under Build and deployment, choose:

  • Source: Deploy from a branch
  • Branch: main
  • Folder: /(root)
Step 3 — Save and wait

Click Save. Wait about one minute, refresh the Pages settings, and click the live website link when it appears.

03 · EXPECTED RESULT

My Published Website

After GitHub Pages finishes deploying, my repository should be available at this address:

Live URL

https://the-anar.github.io/webpro-w9/

Open Live Website ↗

04 · VERIFICATION

Check the Result

After deployment, verify that the website opens correctly and that the homepage is displayed.

  • The repository is public.
  • GitHub Pages is enabled.
  • The selected branch is main.
  • The selected folder is /(root).
  • The published website opens successfully.

05 · CONCLUSION

What I Learned

I learned how to enable GitHub Pages from repository settings. By selecting the main branch and root folder, I can publish my static website and access it through a public web address.

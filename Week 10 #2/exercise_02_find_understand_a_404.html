Week 10.2 · Practice Exercise 02

Find and Understand a 404 Page

Test a URL that does not exist, identify the HTTP 404 status, and understand how GitHub Pages handles missing pages.

01. Objective

A 404 error means that the requested page could not be found. In this exercise, I will visit a page that does not exist in my published website and examine the result.

02. Visit a URL That Does Not Exist

Step 1 — Open an incorrect URL

Add a filename that does not exist to the end of my GitHub Pages website address. 

https://the-anar.github.io/webpro-w9/this-does-not-exist.html

Open the test URL

Step 2 — Check the HTTP status code

I can use the following command in a terminal to check the server response: 

curl.exe -s -o NUL -w "%{http_code}" https://the-anar.github.io/webpro-w9/this-does-not-exist.html

If the page is missing, the expected HTTP status code is:

404

Not Found

03. Understand the Default 404 Page

Without a custom error page, GitHub Pages displays its generic error page titled:

Page not found · GitHub Pages

The requested page could not be found.

This is a generic GitHub Pages error page rather than a page designed for my own website.

What problems does it have?

  • It uses GitHub's generic branding.
  • It does not provide a clear link back to my portfolio.
  • It does not match my website's design.
  • It gives visitors little guidance about what to do next.

04. Is This a Good User Experience?

Not really. A better 404 page should clearly explain that the requested page is missing and help visitors return to the main website.

What should a good 404 page include?

  • A clear message that the page was not found.
  • The same visual design as the rest of the website.
  • A link that takes visitors back to the homepage.
  • Simple and helpful instructions.

05. Conclusion

I learned that an HTTP 404 status means the requested page does not exist. GitHub Pages displays a generic error page when a custom 404 page is not provided.

In the next exercise, I will create my own 404.html page so visitors can receive a more helpful message and return to my website.

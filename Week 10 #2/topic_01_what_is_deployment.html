01 · INTRODUCTION

What Is Deployment?

Deployment is the process of making a website or web application available to people on the internet. During development, a website usually runs on your own computer. Deployment publishes the project so other people can visit it through a public URL.

Local Development vs. Deployment

Local development: You build and test your website on your own computer. It may be available only through an address such as localhost.

Deployment: You publish your website using a hosting service. Other people can access it through an internet URL.

02 · THE DEPLOYMENT PROCESS

From Your Laptop to the Internet

A typical GitHub Pages deployment follows four main stages.

01 · Develop Write and test your HTML, CSS, and JavaScript locally.
02 · Push Upload your project and commits to a GitHub repository.
03 · Build GitHub Pages prepares your repository as a website.
04 · Publish Your website becomes accessible through a public URL.

03 · DEPLOYMENT OPTIONS

Where Can You Deploy a Website?

There are several ways to host a website. The best option depends on the project's size, features, and requirements.

GitHub Pages

A free hosting service for static websites. It works well for HTML, CSS, and JavaScript projects and is ideal for this course.

Best for: Portfolios and coursework.

Netlify / Vercel

Hosting platforms with free tiers and convenient deployment workflows. They can automatically publish updates from a Git repository.

Best for: Modern frontend projects.

Cloud Servers

Services such as AWS and Google Cloud provide more control over servers, infrastructure, and backend applications.

Best for: Advanced applications.

04 · WHY DEPLOYMENT MATTERS

Why Do We Deploy Websites?

  • Public access: Anyone with the URL can visit the website.
  • Sharing: You can show your work to professors, teammates, and employers.
  • Real-world testing: You can check how your website works outside your local computer.
  • Portfolio: You can present your projects as published websites.
  • Updates: With GitHub Pages, pushing new changes can trigger a new deployment.

06 · SUMMARY

What I Learned

Deployment is the process of publishing a website so that people can access it online. A common workflow is to develop locally, push the code to GitHub, let a hosting service build the website, and then share the published URL.

GitHub Pages is a useful free option for static websites. Other platforms such as Netlify, Vercel, and cloud services provide additional hosting features for different projects.

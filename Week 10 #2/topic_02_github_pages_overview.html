GitHub Pages Overview

Learn how GitHub Pages turns a repository into a public website.

BATSUREN ANAR · STUDENT ID: 202637018

01 · INTRODUCTION

What Is GitHub Pages?

GitHub Pages is a free website hosting service provided by GitHub. It can publish a website directly from files stored in a GitHub repository. This makes it useful for portfolios, documentation, project demonstrations, and coursework.

How It Works

You store your website files in a repository, configure GitHub Pages, and GitHub publishes the supported files as a website that people can visit using a URL.

02 · TYPES OF GITHUB PAGES SITES

User Site vs. Project Site

User / Organization Site

A main website associated with a GitHub account or organization.

username.github.io

The repository must use the special username.github.io name.

Project Site

A website published from an individual project repository.

username.github.io/repo-name

The repository name becomes part of the website URL.

Course Example

A project site for a book search application.

juma2024.github.io/book-search-app

This URL includes the GitHub username and repository name.

03 · MAIN FEATURES

Why Use GitHub Pages?

Free Hosting

GitHub Pages is available without paying for a separate hosting server for eligible public repositories.

Automatic Updates

When you push changes to the configured publishing source, GitHub can build and publish the updated site.

HTTPS Support

Published websites support HTTPS, helping protect connections between visitors and the site.

No Server Setup

You do not need to manage a physical server or install web server software yourself.

Custom Domain

You can optionally configure a domain name that you own to use with your website.

GitHub Integration

Your website files and version history stay connected to the same repository.

04 · EXAMPLE

My GitHub Pages Website

I have published my personal portfolio using GitHub Pages. It is a project site connected to my portfolio repository.

GitHub repository

github.com/The-Anar/portfolio

Published website

the-anar.github.io/portfolio/

The repository name, portfolio, appears at the end of the project-site URL.

07 · SUMMARY

What I Learned

GitHub Pages provides a convenient way to host static websites directly from a GitHub repository. There are two main types: user or organization sites, and project sites.

A project-site URL contains the GitHub username and repository name. GitHub Pages also provides useful features such as automatic publishing, HTTPS, and optional custom domains.

WEEK 10.2 · TOPIC 03

Enable GitHub Pages

Learn how to publish a repository as a live website using GitHub repository settings.

BATSUREN ANAR · STUDENT ID: 202637018

01 · BEFORE YOU START

Prepare Your Repository

Before enabling GitHub Pages, make sure your website files have been pushed to a GitHub repository. For a simple static website, the repository should contain an index.html file in the publishing folder.

Example repository structure

my-website/
├── index.html
├── style.css
├── app.js
├── images/
└── README.md

The example uses the main branch and the repository root folder.

02 · STEP-BY-STEP GUIDE

Enable GitHub Pages in Repository Settings

1Open Your Repository

Go to GitHub and open the repository you want to publish.

2Open Settings

Click the Settings tab in the repository's top navigation.

3Find Pages

In the left sidebar, find Pages under the Code and automation section.

4Choose a Source

Under Build and deployment, select Deploy from a branch as the source.

5Select Branch and Folder

Choose main as the branch and /(root) as the folder, if your index.html is in the repository root.

6Click Save

Click Save. GitHub will begin building and publishing your website.

03 · AFTER SAVING

Wait for Deployment

After saving the Pages settings, GitHub starts a deployment process. It may take a few minutes before the website is available.

How to verify publication

  1. Return to the repository's Settings → Pages section.
  2. Wait for GitHub to display the published website URL.
  3. Open the URL in a new browser tab.
  4. Check that the homepage and its resources load correctly.

The exact deployment time can vary. Check the Pages status or Actions tab if publishing takes longer.

06 · SUMMARY

What I Learned

GitHub Pages can be enabled from a repository's Settings → Pages section. For a basic project website, I can choose the main branch and root folder, then save the settings to start deployment.

After GitHub finishes publishing, I can open the generated URL and test the live website. Future pushes to the configured publishing source can trigger updates.

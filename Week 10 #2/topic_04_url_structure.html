GitHub Pages URL Structure

Understand how usernames and repository names determine your published website address.

BATSUREN ANAR · STUDENT ID: 202637018

01 · URL BASICS

How Does a GitHub Pages URL Work?

A GitHub Pages URL is the web address used to visit a published website. For a project site, the address is normally made from the GitHub username, the GitHub Pages domain, and the repository name.

Project-site URL structure

https://username.github.io/repository-name/

The username identifies the GitHub account. The repository name identifies the project being published.

02 · TWO URL TYPES

User Site vs. Project Site

User / Organization Site

A main website for a GitHub account or organization.

https://username.github.io/

The special repository name is username.github.io.

Project Site

A website published from a regular project repository.

https://username.github.io/repository-name/

The repository name appears after the username's domain.

03 · URL EXAMPLE

Understanding a Real Example

Suppose the GitHub username is jiyeon99 and the repository name is portfolio.

GitHub repository:

github.com/jiyeon99/portfolio

GitHub Pages website:

jiyeon99.github.io/portfolio/

The exact repository name becomes part of the project-site URL.

04 · REPOSITORY NAMING

Choose Repository Names Carefully

  • Use lowercase letters when naming a repository.
  • Use hyphens instead of spaces.
  • Keep the name short and easy to understand.
  • Remember that renaming a repository can change its project-site URL.

Good and bad examples

Good: my-portfolio, book-search-app, web-programming

Avoid: My Portfolio, Book Search App

05 · FILE PATHS

Use Correct File Paths

Your HTML pages also need correct paths to CSS, JavaScript, and images. Relative paths are especially important when a project is hosted inside a repository subfolder.

Example repository

portfolio/
├── index.html
├── about.html
├── style.css
└── images/
    └── profile.jpg

Correct relative paths:

<link rel="stylesheet" href="./style.css">
<a href="./about.html">About</a>
<img src="./images/profile.jpg" alt="Profile">

A path beginning with / points to the domain root. That can cause problems on project sites because the repository name is part of the URL.

08 · SUMMARY

What I Learned

GitHub Pages project URLs are based on the GitHub username and repository name. User sites use the username.github.io address, while project sites add the repository name after it.

Repository names should be clear and consistent. Correct relative paths help HTML pages load their stylesheets, scripts, and images when published online.

WEEK 10.2 · TOPIC 05

What Works and What Doesn't on GitHub Pages

Learn the difference between static websites and server-side applications.

BATSUREN ANAR · STUDENT ID: 202637018

01 · INTRODUCTION

GitHub Pages Is Static Hosting

GitHub Pages publishes static website files to the internet. It is designed for websites that can run in a visitor's browser without needing a server to process each request.

Static website:

HTML creates the structure, CSS controls the appearance, and JavaScript adds browser-side interaction.

Server-side application:

A server receives requests, runs backend code, and may communicate with a database.

02 · WHAT WORKS

Technologies Supported by GitHub Pages

HTML

Creates the content and structure of web pages.

CSS

Controls colors, layouts, typography, and responsive design.

JavaScript

Adds browser-side features such as buttons, menus, and interactive tools.

Images and Fonts

Static assets such as PNG, JPG, SVG, and font files can be published.

JSON Files

JavaScript can load and use static JSON data in the browser.

Frontend Frameworks

Frameworks such as React can work when their build output is published as static files.

03 · WHAT DOES NOT WORK

Server-Side Features Not Provided

PHP

GitHub Pages does not execute PHP code on a server.

Python Backend

Flask and Django applications need a server to run.

Node.js / Express

GitHub Pages cannot run a persistent Node.js backend.

Databases

It does not provide a database server such as MySQL or PostgreSQL.

Server File Writes

A static hosting server cannot run backend code to save uploaded files.

Server Authentication

Backend login systems and server-managed sessions require another service.

04 · STATIC VS DYNAMIC

Compare the Two Types

Static Website

  • Files are prepared before visitors access them.
  • Runs in the browser.
  • Can be hosted on GitHub Pages.
  • Example: a personal portfolio.

Dynamic Backend Website

  • Server processes requests.
  • Can use databases and backend logic.
  • Needs backend hosting.
  • Example: an online store with server-managed accounts.

05 · EXTERNAL SERVICES

Can a Static Website Use an API?

Yes. A static website can communicate with an external API using browser JavaScript and fetch(). The API must allow the request, and private API keys should not be placed in public frontend code.

Example

fetch("https://api.example.com/data")
  .then(response => response.json())
  .then(data => {
    console.log(data);
  });

This example requests data from an external service. It does not create a backend server on GitHub Pages.

08 · SUMMARY

What I Learned

GitHub Pages is suitable for static websites using HTML, CSS, JavaScript, images, and other static files. Frontend frameworks can also work when their output is built into static files.

Backend technologies such as PHP, Python Flask, Node.js servers, and databases need a separate backend hosting service.

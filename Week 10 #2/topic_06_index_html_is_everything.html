WEEK 10.2 · TOPIC 06

index.html Is Everything

Understand why the correct homepage filename and repository structure matter for deployment.

BATSUREN ANAR · STUDENT ID: 202637018

01 · INTRODUCTION

What Is index.html?

When someone visits a website without specifying a particular file, the web server normally looks for a default homepage. For a basic GitHub Pages website, that file is usually index.html.

Example

When a visitor opens:

https://username.github.io/portfolio/

GitHub Pages looks for the homepage file in the configured publishing directory.

02 · EXACT FILENAME

Use the Correct Filename

The filename should be exactly index.html.

Correct

  • index.html
  • Lowercase letters
  • HTML file extension

Incorrect for the default homepage

  • Index.html
  • homepage.html
  • index.htm

Other HTML pages can have any filename, but the default homepage should use the expected entry-point name.

03 · FILE LOCATION

Put index.html in the Publishing Folder

If your GitHub Pages source is set to the repository root, the homepage should be directly inside the root folder.

Correct repository structure

portfolio/
├── index.html
├── about.html
├── style.css
├── script.js
└── images/
    └── profile.jpg

Correct: index.html is in the root folder.

Potentially incorrect structure

portfolio/
└── website/
    ├── index.html
    ├── style.css
    └── script.js

Problem: If Pages publishes from the repository root, it will not automatically use the index.html inside the website folder.

04 · PUBLISHING SOURCE

Check the GitHub Pages Source

GitHub Pages can publish from a selected branch and folder. The publishing source determines where GitHub looks for your website files.

  1. Open your GitHub repository.
  2. Go to Settings.
  3. Select Pages.
  4. Check the selected branch, such as main.
  5. Check the selected folder, such as /(root).
  6. Make sure index.html exists in that folder.

05 · COMMON PROBLEMS

Why Is My Homepage Not Loading?

404 Error

The homepage file may be missing or placed in the wrong directory.

Wrong Filename

The file may be named Index.html instead of index.html.

Wrong Publishing Folder

Pages may be configured to publish from a different folder.

Old Website Version

The latest commit may not have finished deploying. Refresh after deployment completes.

08 · SUMMARY

What I Learned

The default homepage of a GitHub Pages website should be named index.html. Its location must match the repository's configured publishing source.

Checking the filename, folder structure, and Pages settings can help prevent common deployment errors such as a 404 page.

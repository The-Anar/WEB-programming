ProfileCard Component

Create a reusable student profile card using React components and props.

BATSUREN ANAR · STUDENT ID: 202637018

1. Exercise Objective

The goal of this exercise is to create a reusable ProfileCard component that receives information through props and displays a person's profile.

  • Create a ProfileCard functional component.
  • Receive name, role, and email through props.
  • Display the user's profile information.
  • Use a default avatar when no avatar URL is provided.
  • Make the component reusable with different information.

2. React Implementation

ProfileCard Component

function ProfileCard({
    name,
    role,
    email,
    avatarUrl = "https://via.placeholder.com/80"
}) {
    return (
        <div className="profile-card">
            <img src={avatarUrl} alt={`${name}'s avatar`} />
            <h2>{name}</h2>
            <p>{role}</p>
            <a href={`mailto:${email}`}>
                {email}
            </a>
        </div>
    );
}

The component receives four props. The avatarUrl prop has a default value, so the component can still work when no image URL is provided.

Using the Component

function App() {
    return (
        <div>
            <ProfileCard
                name="Anar"
                role="Computer Engineering Student"
                email="anar@example.com"
            />

            <ProfileCard
                name="Alex"
                role="Web Developer"
                email="alex@example.com"
                avatarUrl="/images/alex.jpg"
            />
        </div>
    );
}

4. Requirements Checklist

  • ProfileCard is a functional component.
  • Name, role, and email are received through props.
  • Avatar URL is optional.
  • A default avatar is used when the URL is missing.
  • The component displays all profile information.
  • The component can be reused with different prop values.

5. What I Learned

Through this exercise, I practiced creating a reusable functional component and passing information through props.

I also learned how default prop values help prevent missing information and make components more flexible.

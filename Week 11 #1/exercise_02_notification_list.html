Notification List

Render notification data using arrays, map(), keys, and conditional rendering.

BATSUREN ANAR · STUDENT ID: 202637018

1. Exercise Objective

Build a notification list that displays multiple notification objects. Each notification has a message and a type.

  • Store notifications in an array of objects.
  • Use .map() to render each notification.
  • Use a unique key for every React list item.
  • Use conditional rendering to show different icons.

2. React Implementation

Notification Data

const notifications = [
    { id: 1, type: "success", message: "Assignment submitted!" },
    { id: 2, type: "warning", message: "Deadline is tomorrow." },
    { id: 3, type: "info", message: "A new course is available." }
];

Notification Component

function NotificationItem({ notification }) {
    let icon = "ℹ️";

    if (notification.type === "success") {
        icon = "✅";
    } else if (notification.type === "warning") {
        icon = "⚠️";
    }

    return (
        <div className="notification">
            <span>{icon}</span>
            <p>{notification.message}</p>
        </div>
    );
}

function NotificationList() {
    return (
        <div>
            {notifications.map((item) => (
                <NotificationItem
                    key={item.id}
                    notification={item}
                />
            ))}
        </div>
    );
}

The key uses each notification's unique id. This helps React identify list items when the list changes.

4. Requirements Checklist

  • Notifications are stored as objects in an array.
  • Each notification has an id, type, and message.
  • The list is rendered using map().
  • Each React list item has a unique key.
  • Different notification types display different icons.
  • The list can display multiple notifications.

5. What I Learned

I learned how to render an array of objects using .map() and why React needs a unique key for each item.

I also practiced conditional rendering by displaying different icons depending on the notification type.

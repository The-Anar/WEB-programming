Card with props.children

Learn how to create reusable components that wrap and display different content.

BATSUREN ANAR · STUDENT ID: 202637018

1. Exercise Objective

In React, props.children allows a component to receive and display content placed between its opening and closing tags.

  • Create a reusable Card functional component.
  • Receive a title through props.
  • Display nested content using props.children.
  • Reuse the Card component with different content.

2. React Implementation

Creating the Card Component

function Card({ title, children }) {
    return (
        <div className="card">
            <h2>{title}</h2>
            <div className="card-content">
                {children}
            </div>
        </div>
    );
}

The title prop provides the card heading. The children prop contains everything placed inside the Card component.

Using the Card Component

function App() {
    return (
        <div>
            <Card title="About Me">
                <p>I am a computer engineering student.</p>
            </Card>

            <Card title="My Goals">
                <ul>
                    <li>Learn React</li>
                    <li>Build projects</li>
                </ul>
            </Card>
        </div>
    );
}

6. What I Learned

I learned that props.children allows components to receive content from their parent.

This makes components more flexible because the same Card component can be reused with different headings and content without rewriting its structure.

Project Overview

This project is a React-based Portfolio Gallery that displays four web development projects. Users can filter the projects by technology using interactive filter buttons.

The application uses React components, props, arrays, the map() method, conditional rendering, and useState to manage the selected technology filter.

Component Structure

App
├── FilterBar
└── ProjectList
    └── ProjectCard
  • App: Manages the selected filter using useState and filters project data.
  • FilterBar: Displays technology buttons and indicates the active filter using aria-pressed.
  • ProjectList: Renders the filtered projects using map() and stable keys.
  • ProjectCard: Displays project titles, descriptions, technology tags, GitHub links, and live demos.

Project Features

  • Four project cards displayed in a responsive grid.
  • Technology filters generated from a predefined list.
  • Interactive filtering using React useState.
  • Active filter indication using aria-pressed.
  • GitHub and live demo links for every project.
  • Responsive layout for mobile and desktop screens.
  • Empty-state message when no projects match a filter.

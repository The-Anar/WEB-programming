1. Assignment Overview

Task 11-A focuses on building a reusable React StudentProfileCard component using props.

The application displays multiple student profiles using one reusable component. Student information is passed into the component through five props.

2. Learning Objectives

OBJECTIVE 01

Reusable Components

Create a separate functional React component that can be reused throughout the application.

OBJECTIVE 02

Props

Pass student information into a component using props and display the received values.

OBJECTIVE 03

Rendering Lists

Use JavaScript map() to render multiple student cards from an array of student objects.

OBJECTIVE 04

Component Composition

Organize the application into smaller, reusable components with clear responsibilities.

3. Component Requirements

The StudentProfileCard component uses exactly five props to receive student information:

Prop Purpose
name Student's name
studentId Student identification number
major Academic major
year Current study year
gpa Grade point average

Component Structure

function StudentProfileCard({
    name,
    studentId,
    major,
    year,
    gpa
}) {
    return (
        <div className="student-card">
            <h2>{name}</h2>
            <p>Student ID: {studentId}</p>
            <p>Major: {major}</p>
            <p>Year: {year}</p>
            <p>GPA: {gpa}</p>
        </div>
    );
}

4. Student Directory Requirements

The application renders three student profile cards using the reusable StudentProfileCard component.

  • Display the student's name.
  • Display the student ID.
  • Display the academic major.
  • Display the study year.
  • Display the GPA.
  • Render the student list using map().
  • Provide a unique key for each rendered card.

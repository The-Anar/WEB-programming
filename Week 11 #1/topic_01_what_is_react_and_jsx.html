⚛ What is React & JSX?

Learn what React is, understand how JSX works, and discover how JavaScript and HTML-like syntax come together to build interactive user interfaces.

1. What is React?

React is a JavaScript library used to build user interfaces. It allows developers to create websites using small, reusable pieces called components.

Instead of writing one large page, developers can divide the interface into smaller parts, such as a navigation bar, profile card, button, or notification list.

💡 In simple words: React helps developers build websites by combining reusable components.

Why use React?

  • Build reusable user interface components.
  • Organize large applications into smaller parts.
  • Update the interface when data changes.
  • Make complex interfaces easier to manage.

2. What is JSX?

JSX stands for JavaScript XML. It is a syntax extension that allows developers to write HTML-like markup directly inside JavaScript code.

JSX makes React components easier to read because the interface structure can be written in a familiar format. 

// JSX example

const name = "Anar";

const element = (
    <h1>Hello, {name}!</h1>
);
💡 JavaScript expressions can be inserted inside JSX using curly braces { }.

3. How JSX Works

Browsers do not directly understand JSX. Before the code runs, a compiler or build tool transforms JSX into JavaScript function calls.

What developers write:

const element = (
    <h1 className="title">
        Hello, Anar!
    </h1>
);

Conceptually, it becomes:

const element = React.createElement(
    'h1',
    { className: 'title' },
    'Hello, Anar!'
);

You normally write JSX, while tools such as Babel or a framework's build system handle the transformation.

4. Important JSX Rules

HTML

<div class="app">
    <label for="email">
        Email
    </label>
</div>

JSX

<div className="app">
    <label htmlFor="email">
        Email
    </label>
</div>

Remember these rules:

  • Use className instead of class.
  • Use htmlFor instead of for on labels.
  • Close all elements, including <img />, <input />, and <br />.
  • Return one parent element, or use a Fragment.
  • Put JavaScript expressions inside curly braces.

Using a Fragment

A Fragment allows a component to return multiple elements without adding an unnecessary HTML container. 

function Welcome() {
    return (
        <>
            <h1>Welcome!</h1>
            <p>Learning React and JSX.</p>
        </>
    );
}

5. Complete JSX Example

The following example combines a JavaScript variable, JSX markup, and a JavaScript expression. 

function App() {
    const user = 'Anar';

    return (
        <div className="app">
            <h1>Welcome, {user}!</h1>
            <p>Today: {new Date().toDateString()}</p>
            <img
                src="photo.jpg"
                alt="Profile"
            />
        </div>
    );
}

In this example, user is a JavaScript variable. The curly braces insert its value into the JSX heading.

7. Key Takeaways

  • React is a JavaScript library for building user interfaces.
  • Components are reusable parts of a user interface.
  • JSX lets developers write HTML-like markup inside JavaScript.
  • JSX is transformed into JavaScript before execution.
  • Use className instead of class.
  • Use curly braces to insert JavaScript expressions.
  • Return one root element or use a Fragment.

Functional Components

Learn how to create reusable React components using JavaScript functions and JSX.

BATSUREN ANAR · STUDENT ID: 202637018

1. What is a Functional Component?

A functional component is a JavaScript function that returns JSX. It describes a part of the user interface.

Components help developers divide a website into smaller and reusable sections. Each component can have its own purpose.

Basic Example

function Greeting() {
    return <h2>Hello, World!</h2>;
}

The Greeting function is a React component because it starts with a capital letter and returns JSX.

2. Component Naming Rules

Start with a capital letter

React component names should begin with an uppercase letter.

function Welcome() {
    return <h2>Welcome!</h2>;
}
Correct

Use meaningful names

Choose names that explain what the component displays or does.

function StudentCard() {
    return <div>Student</div>;
}
Recommended

Avoid lowercase names

Lowercase names are interpreted as regular HTML elements in JSX.

function greeting() {
    return <h2>Hello</h2>;
}
Avoid

3. Using a Component

After creating a component, you can use it inside another component with JSX syntax. Write its name like a self-closing HTML element. 

function Greeting() {
    return <h2>Hello, World!</h2>;
}

function App() {
    return (
        <div>
            <Greeting />
            <Greeting />
        </div>
    );
}

The Greeting component is used twice inside App. This demonstrates component reusability.

4. Arrow Function Components

Functional components can also be written using arrow function syntax. Both examples below define a component that returns JSX.

Regular Function

function Welcome() {
    return <h2>Welcome to React!</h2>;
}

Arrow Function

const Welcome = () => {
    return <h2>Welcome to React!</h2>;
};

Both styles are commonly used in React projects.

5. Returning Multiple Elements

A React component must return one parent element. If you want to return multiple elements without adding an extra HTML container, you can use a Fragment. 

function StudentInfo() {
    return (
        <>
            <h2>Student Information</h2>
            <p>Name: Anar</p>
            <p>University: Gachon University</p>
        </>
    );
}

The empty tags <> and </> represent a React Fragment.

6. Component Structure Example

Student Profile Components

A page can be organized into smaller components, such as a header, student profile, and footer. 

function Header() {
    return <h1>My Student Page</h1>;
}

function StudentProfile() {
    return (
        <div>
            <h2>Batsuren Anar</h2>
            <p>Computer Engineering Student</p>
        </div>
    );
}

function Footer() {
    return <p>Gachon University</p>;
}

function App() {
    return (
        <>
            <Header />
            <StudentProfile />
            <Footer />
        </>
    );
}

7. Key Takeaways

  • A functional component is a JavaScript function that returns JSX.
  • Component names must start with an uppercase letter.
  • Components can be reused in other components.
  • Arrow functions are another way to write functional components.
  • A component must return one parent element.
  • React Fragments allow multiple elements without an extra container.

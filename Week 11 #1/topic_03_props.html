Props: Passing Data

Learn how React components receive and display information using props.

BATSUREN ANAR · STUDENT ID: 202637018

1. What are Props?

Props is short for properties. They allow a parent component to pass information to a child component.

Props make components reusable because the same component can display different information depending on the values it receives.

Parent Component

Sends information to another component.

Props

Carry information from the parent to the child.

Child Component

Receives and displays the information.

2. Passing Props to a Component

Props are passed to a component using attributes in JSX. The child component receives these values through its props parameter. 

function Greeting(props) {
    return <h2>Hello, {props.name}!</h2>;
}

function App() {
    return (
        <div>
            <Greeting name="Anar" />
            <Greeting name="Alex" />
        </div>
    );
}

The Greeting component receives a different name each time it is used.

3. Accessing Props

A component can access a prop using the props object. Each property is available through its name. 

function StudentCard(props) {
    return (
        <div>
            <h2>{props.name}</h2>
            <p>Major: {props.major}</p>
            <p>Year: {props.year}</p>
        </div>
    );
}

function App() {
    return (
        <StudentCard
            name="Anar"
            major="Computer Engineering"
            year={2026}
        />
    );
}

4. Props Destructuring

Instead of writing props.name repeatedly, you can use destructuring to extract the values directly from props.

Without Destructuring

function Greeting(props) {
    return <h2>Hello, {props.name}!</h2>;
}

With Destructuring

function Greeting({ name }) {
    return <h2>Hello, {name}!</h2>;
}

Both examples work. Destructuring makes the code shorter and easier to read.

5. Default Prop Values

A component can provide a default value for a prop. The default value is used when the parent does not provide that prop. 

function StudentCard({
    name = "Unknown Student",
    role = "Student"
}) {
    return (
        <div>
            <h2>{name}</h2>
            <p>{role}</p>
        </div>
    );
}

// Uses the default values
<StudentCard />

// Uses the provided values
<StudentCard name="Anar" role="Developer" />

6. Props are Read-Only

Props should not be changed by the child component. They are read-only values passed from the parent. 

function Greeting({ name }) {
    // Correct: use the received value
    return <h2>Hello, {name}!</h2>;
}

If information needs to change, React uses other features such as state. Props themselves should not be modified.

8. Key Takeaways

  • Props allow parent components to pass data to child components.
  • Props are received through the component's parameter.
  • Use props.name to access a property.
  • Destructuring provides a shorter way to access props.
  • Default values can be provided when props are missing.
  • Props are read-only and should not be modified by child components.

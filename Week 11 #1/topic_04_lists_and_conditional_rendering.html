Lists & Conditional Rendering

Learn how to display collections of data and show different content based on conditions in React.

BATSUREN ANAR · STUDENT ID: 202637018

1. Rendering Lists with map()

React can display multiple items by using JavaScript's map() method. The method goes through an array and creates an element for each item. 

const students = ["Anar", "Alex", "Sara"];

function StudentList() {
    return (
        <ul>
            {students.map((student) => (
                <li key={student}>{student}</li>
            ))}
        </ul>
    );
}

Each student in the array becomes a list item.

2. Why is key Important?

When rendering a list, React needs a unique key for each item. Keys help React identify which items have changed, been added, or been removed. 

const courses = [
    { id: 1, name: "Web Programming" },
    { id: 2, name: "Discrete Mathematics" },
    { id: 3, name: "Computer Science" }
];

function CourseList() {
    return (
        <ul>
            {courses.map((course) => (
                <li key={course.id}>
                    {course.name}
                </li>
            ))}
        </ul>
    );
}

Use a stable and unique value, such as an item's ID. Avoid using an array index as a key when items can be reordered or removed.

3. Conditional Rendering

Conditional rendering means displaying different content depending on a condition. React uses normal JavaScript expressions to decide what appears on the screen.

Ternary Operator

Use a ternary when you want to choose between two results.

function LoginMessage({ isLoggedIn }) {
    return (
        <p>
            {isLoggedIn
                ? "Welcome back!"
                : "Please log in."}
        </p>
    );
}

Logical AND (&&)

Use && when content should appear only if a condition is true.

function Notifications({ count }) {
    return (
        <div>
            {count > 0 && (
                <p>You have new messages.</p>
            )}
        </div>
    );
}

Early Return

Return early when a component should not display its normal content.

function Profile({ user }) {
    if (!user) {
        return <p>No user found.</p>;
    }

    return <h2>{user.name}</h2>;
}

4. Ternary Operator Example

A ternary expression checks a condition and chooses one of two possible outputs. 

const isLoggedIn = true;

return (
    <div>
        {isLoggedIn
            ? <h2>Welcome back!</h2>
            : <h2>Please log in.</h2>}
    </div>
);

7. Key Takeaways

  • Use map() to render arrays into lists of elements.
  • Give each rendered list item a unique and stable key.
  • Use the ternary operator to choose between two outputs.
  • Use && to display content only when a condition is true.
  • Use an early return when a component needs to display a different result.
  • Conditional rendering uses ordinary JavaScript conditions.

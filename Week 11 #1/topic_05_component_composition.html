Component Composition

Learn how to combine smaller React components to build organized and reusable user interfaces.

BATSUREN ANAR · STUDENT ID: 202637018

1. What is Component Composition?

Component composition means building a larger user interface by combining smaller components.

Instead of creating one large component, developers divide the interface into smaller parts. Each part has a specific responsibility.

Avatar

Displays a user's image or initials.

Badge

Displays a small label, status, or category.

StudentCard

Combines the avatar, name, and student information.

2. Small Components

A component should focus on one clear task. For example, an Avatar component can display a user's initials. 

function Avatar({ name }) {
    return (
        <div className="avatar">
            {name.charAt(0)}
        </div>
    );
}

A Badge component can display a user's role or status. 

function Badge({ label }) {
    return (
        <span className="badge">
            {label}
        </span>
    );
}

3. Combining Components

Smaller components can be combined inside a larger component. The StudentCard below uses Avatar and Badge. 

function Avatar({ name }) {
    return <div className="avatar">
        {name.charAt(0)}
    </div>;
}

function Badge({ label }) {
    return <span className="badge">
        {label}
    </span>;
}

function StudentCard({ name, major, role }) {
    return (
        <div className="student-card">
            <Avatar name={name} />
            <h2>{name}</h2>
            <p>{major}</p>
            <Badge label={role} />
        </div>
    );
}

function App() {
    return (
        <StudentCard
            name="Anar"
            major="Computer Engineering"
            role="Student"
        />
    );
}

4. The props.children Property

React provides a special prop called children. It represents the content placed between a component's opening and closing tags. 

function Card({ title, children }) {
    return (
        <div className="card">
            <h2>{title}</h2>
            <div>{children}</div>
        </div>
    );
}

function App() {
    return (
        <Card title="About Me">
            <p>I am a student at Gachon University.</p>
            <p>I study Computer Engineering.</p>
        </Card>
    );
}

The Card component controls the outer layout while its children provide the content inside it.

5. Why Use Component Composition?

Reusability

The same small component can be used in many places.

Organization

Smaller components make large interfaces easier to understand.

Maintenance

A component can be updated without rewriting the entire page.

7. Key Takeaways

  • Component composition combines smaller components into larger interfaces.
  • Each component should have a clear responsibility.
  • Components can be reused in different parts of an application.
  • Props allow components to receive information from their parents.
  • props.children displays content placed between component tags.
  • Composition makes applications easier to organize and maintain.

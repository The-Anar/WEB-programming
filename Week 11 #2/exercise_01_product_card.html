E1 · ProductCard Challenge

Build a reusable ProductCard component using props to display product information, prices, ratings, and stock availability.

EXERCISE OVERVIEW

Challenge Description

Create a reusable ProductCard component that receives product information through four props. Each card should display the product name, price in Korean won, rating, and stock status.

Required Props

  • name — The product name.
  • price — The product price in KRW.
  • rating — The product rating.
  • inStock — A boolean indicating whether the product is available.

Bonus Requirements

  • Display the rating in the format rating / 5 stars.
  • Show an "Out of stock" label when inStock is false.

IMPLEMENTATION

React Code

The ProductCard component receives its information through props. The ProductList component uses map() to create a card for every product. 

function ProductCard({ name, price, rating, inStock }) {
  return (
    <article>
      <h2>{name}</h2>
      <p>₩{price.toLocaleString('ko-KR')}</p>
      <p>{rating} / 5 stars</p>

      {inStock
        ? <span>In stock</span>
        : <span>Out of stock</span>}
    </article>
  );
}

const products = [
  {
    id: 'earbuds',
    name: 'Wireless Earbuds',
    price: 89000,
    rating: 4.5,
    inStock: true
  },
  {
    id: 'keyboard',
    name: 'Mechanical Keyboard',
    price: 120000,
    rating: 4.8,
    inStock: false
  },
  {
    id: 'mouse',
    name: 'Gaming Mouse',
    price: 45000,
    rating: 4.2,
    inStock: true
  }
];

function ProductList() {
  return (
    <div>
      {products.map((p) => (
        <ProductCard key={p.id} {...p} />
      ))}
    </div>
  );
}

ReactDOM.createRoot(
  document.getElementById('root')
).render(<ProductList />);

KEY CONCEPTS

What This Exercise Demonstrates

1. Props

Props allow a component to receive data from its parent. Each ProductCard receives name, price, rating, and inStock.

2. Array map()

The map() method creates a ProductCard for every object in the products array.

3. Spread Syntax

The expression {'{...p}'} passes all properties of a product object to the component as individual props.

4. Conditional Rendering

The inStock value determines whether the card displays "In stock" or "Out of stock".

5. Number Formatting

toLocaleString('ko-KR') formats numbers using Korean number conventions. For example, 89000 becomes 89,000.

Key takeaway: A single reusable component can display different products simply by receiving different props.

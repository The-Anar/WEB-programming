E2 · Course Catalog

Create reusable course cards from an array of objects and display different badges depending on whether a course is required or elective.

EXERCISE OVERVIEW

Challenge Description

Create a reusable CourseCard component that receives course information through props. Render multiple courses from an array and use the required prop to display the correct course badge.

Required Props

  • title — The course name.
  • instructor — The instructor's name.
  • credits — The number of course credits.
  • required — A boolean indicating whether the course is mandatory or elective.

Expected Behavior

  • Render course cards using an array and the map() method.
  • Show "필수 · Required" when required is true.
  • Show "선택 · Elective" when required is false.
  • Use a unique key for each rendered course.

IMPLEMENTATION

React Code

The CourseCard component receives four props. The CourseCatalog component maps through the courses array and passes each course's information into a separate card. 

function CourseCard({ title, instructor, credits, required }) {
  return (
    <article>
      <h2>{title}</h2>
      <p>Instructor: {instructor}</p>
      <p>Credits: {credits}</p>

      <span>
        {required
          ? '필수 · Required'
          : '선택 · Elective'}
      </span>
    </article>
  );
}

const courses = [
  {
    id: 1,
    title: 'Web Programming',
    instructor: 'Dr. Toshpulatov',
    credits: 3,
    required: true
  },
  {
    id: 2,
    title: 'Database Systems',
    instructor: 'Dr. Kim',
    credits: 3,
    required: true
  },
  {
    id: 3,
    title: 'Mobile App Development',
    instructor: 'Dr. Lee',
    credits: 2,
    required: false
  }
];

function CourseCatalog() {
  return (
    <div>
      {courses.map((c) => (
        <CourseCard
          key={c.id}
          title={c.title}
          instructor={c.instructor}
          credits={c.credits}
          required={c.required}
        />
      ))}
    </div>
  );
}

ReactDOM.createRoot(
  document.getElementById('root')
).render(<CourseCatalog />);

KEY CONCEPTS

What This Exercise Demonstrates

1. Reusable Components

CourseCard is written once and reused to display different courses with different information.

2. Props

The component receives title, instructor, credits, and required from its parent component.

3. Rendering Arrays with map()

The map() method creates a separate CourseCard for every course object in the courses array.

4. Conditional Rendering

The required boolean determines which badge is displayed: "필수 · Required" or "선택 · Elective".

5. Unique Keys

The key property uses each course's unique ID so React can identify individual elements in the list.

Key takeaway: One reusable component can display different course information, while a boolean prop controls which badge appears.

EXERCISE OVERVIEW

Challenge Description

Create a StudentCard component that receives a student's name, student ID, and course through props. Display the information in a simple student profile card.

Required Props

  • name — The student's full name.
  • studentId — The student's university ID.
  • course — The student's course information.

Expected Result

  • Display the student's name in the card header.
  • Display the student ID below the name.
  • Display the course information in the card body.
  • Render the card using the StudentCard component.

IMPLEMENTATION

React Code

The StudentCard component receives three props. The parent component passes my own student information when rendering the card. 

function StudentCard({ name, studentId, course }) {
  return (
    <article>
      <div>
        <h2>{name}</h2>
        <p>ID: {studentId}</p>
      </div>
      <p>{course}</p>
    </article>
  );
}

ReactDOM.createRoot(
  document.getElementById('root')
).render(
  <StudentCard
    name="Batsuren Anar"
    studentId="202637018"
    course="Computer Engineering · Gachon University"
  />
);

KEY CONCEPTS

What This Exercise Demonstrates

1. Functional Components

StudentCard is a functional React component that returns the structure of a student profile card.

2. Props Destructuring

The component receives name, studentId, and course directly through its function parameters.

3. Dynamic Content

JSX expressions display the values passed into the component instead of using fixed text inside the card.

4. Component Reusability

The same StudentCard component can display another student's information by passing different props.

Key takeaway: Props allow one reusable StudentCard component to display different students' information without rewriting the component.

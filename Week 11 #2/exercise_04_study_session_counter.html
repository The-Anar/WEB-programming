WEEK 11.2 · REACT STATE & EVENTS

E4 · Study Session Counter

Use React useState to track completed study sessions and update the count with buttons.

BATSUREN ANAR · STUDENT ID: 202637018

EXERCISE OVERVIEW

Challenge Description

Build a session counter that stores a number in React state. Three buttons allow the user to decrease, increase, or reset the number of completed study sessions.

Requirements

  • Start the counter at zero using useState(0).
  • Increase the count by one when the plus button is clicked.
  • Decrease the count by one when the minus button is clicked.
  • Prevent the count from going below zero.
  • Disable the minus button when the count is zero.
  • Reset the count to zero using the Reset button.

IMPLEMENTATION

React Code

The sessions state stores the current count. Each button calls the state setter to update the value. 

function SessionCounter() {
  const [sessions, setSessions] = useState(0);

  return (
    <section>
      <p aria-live="polite">
        Completed sessions: <strong>{sessions}</strong>
      </p>

      <button
        type="button"
        onClick={() =>
          setSessions((n) => Math.max(0, n - 1))
        }
        disabled={sessions === 0}
      >
        −1 session
      </button>

      <button
        type="button"
        onClick={() => setSessions((n) => n + 1)}
      >
        +1 session
      </button>

      <button
        type="button"
        onClick={() => setSessions(0)}
      >
        Reset
      </button>
    </section>
  );
}

ReactDOM.createRoot(
  document.getElementById('root')
).render(<SessionCounter />);

KEY CONCEPTS

What This Exercise Demonstrates

1. useState

useState(0) creates state for the counter and sets its initial value to zero.

2. Event Handlers

The onClick handlers run when the user clicks the counter buttons.

3. Previous State Updates

setSessions((n) => n + 1) uses the previous state value to calculate the next count.

4. Preventing Negative Values

Math.max(0, n - 1) ensures the counter never decreases below zero.

5. Conditional Button State

The minus button is disabled whenever sessions === 0.

Key takeaway: setSessions((n) => n + 1) uses the previous state value. This is safer than setSessions(sessions + 1) when several updates happen quickly.

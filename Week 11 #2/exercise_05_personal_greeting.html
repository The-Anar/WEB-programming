E5 · Personal Greeting

Create a controlled text input that updates a greeting immediately as the user types.

BATSUREN ANAR · STUDENT ID: 202637018

EXERCISE OVERVIEW

Challenge Description

Build a greeting component with a text input. React state stores the input value, and the greeting changes every time the user types.

Requirements

  • Start with an empty name using useState('').
  • Connect the input to state using the value prop.
  • Update the state using the onChange event.
  • Display the current name in a greeting.
  • Show Guest when the input is empty or contains only spaces.
  • Use aria-live="polite" for the greeting.

IMPLEMENTATION

React Code

The input is controlled by React because its value comes from the name state. The onChange handler updates that state whenever the input changes. 

function Greeting() {
  const [name, setName] = useState('');

  return (
    <section>
      <label htmlFor="greet-name">
        Your name
      </label>

      <input
        id="greet-name"
        type="text"
        value={name}
        onChange={(e) => setName(e.target.value)}
        placeholder="Uuuhaaaiiii"
      />

      <p aria-live="polite">
        Hello, {name.trim() || 'Guest'}!
      </p>
    </section>
  );
}

ReactDOM.createRoot(
  document.getElementById('root')
).render(<Greeting />);

KEY CONCEPTS

What This Exercise Demonstrates

1. Controlled Input

The input's value is controlled by the React state variable name.

2. useState

useState('') creates a state variable with an empty string as its initial value.

3. onChange Event

onChange runs whenever the user changes the input. e.target.value gets the text currently entered.

4. Conditional Fallback

name.trim() || 'Guest' displays Guest if the name is empty or contains only whitespace.

Key takeaway: A controlled input keeps the displayed input value synchronized with React state. Updating the state causes the greeting to render again with the latest name.

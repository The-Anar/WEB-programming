E7 · Show / Hide a Hint

Use boolean state and conditional rendering to show or hide a study hint.

EXERCISE OVERVIEW

Challenge Description

Build a component with a button that toggles a hint. A boolean state variable controls whether the hint is displayed on the page.

Requirements

  • Initialize the state with useState(false).
  • Use a button to change the boolean state.
  • Change the button text between Show hint and Hide hint.
  • Use open && to conditionally render the hint.
  • Use aria-expanded to communicate the current state.
  • Connect the button to the hint using aria-controls.

IMPLEMENTATION

React Code

The open state starts as false. Clicking the button changes its value, and the conditional expression determines whether the hint appears. 

function StudyHint() {
  const [open, setOpen] = useState(false);

  return (
    <section>
      <button
        type="button"
        aria-expanded={open}
        aria-controls="hint"
        onClick={() => setOpen(!open)}
      >
        {open ? 'Hide hint' : 'Show hint'}
      </button>

      {open && (
        <p id="hint">

          then decide which one owns the state.
        </p>
      )}
    </section>
  );
}

KEY CONCEPTS

What This Exercise Demonstrates

1. Boolean State

useState(false) creates a boolean state variable that starts as false.

2. State Toggle

setOpen(!open) changes the current value to its opposite.

3. Conditional Rendering with &&

open && <p>...</p> displays the hint only when open is true.

4. Dynamic Button Text

The conditional expression changes the button label depending on whether the hint is visible.

5. Accessibility Attributes

aria-expanded communicates whether the hint is expanded, while aria-controls identifies the controlled hint element.

Key takeaway: Boolean state can control whether an element appears. The && operator renders the hint only when the condition is true.

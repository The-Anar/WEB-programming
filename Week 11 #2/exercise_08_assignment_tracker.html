E8 · Assignment Tracker

Manage assignment status, filter tasks, and clear completed work using React state.

EXERCISE OVERVIEW

Challenge Description

Build an assignment tracker that allows users to mark tasks as completed, filter the list by status, and remove all completed assignments.

Requirements

  • Initialize the task array with three assignments.
  • Use a checkbox to toggle each task's completed status.
  • Provide All, Pending, and Done filters.
  • Display only tasks matching the selected filter.
  • Show a message when the filtered list is empty.
  • Provide a button to clear all completed assignments.
  • Update objects and arrays without mutating the original state.
  • Derive the filtered list instead of storing it in state.

IMPLEMENTATION

React Code

The tasks array stores assignment data. The filter state controls which assignments are displayed. The visible list is calculated from these two state values. 

function AssignmentTracker() {
  const [tasks, setTasks] = useState([
    { id: 1, title: 'Finish Task 11-A', done: false },
    { id: 2, title: 'Practise useState', done: true },
    { id: 3, title: 'Deploy the portfolio', done: false },
  ]);

  const [filter, setFilter] = useState('all');

  const toggle = (id) => setTasks(
    tasks.map((t) =>
      t.id === id ? { ...t, done: !t.done } : t
    )
  );

  const clearDone = () =>
    setTasks(tasks.filter((t) => !t.done));

  const shown = tasks.filter((t) =>
    filter === 'pending' ? !t.done :
    filter === 'done' ? t.done : true
  );

  return (
    <section>
      <div role="group" aria-label="Filter assignments">
        {['all', 'pending', 'done'].map((f) => (
          <button
            key={f}
            type="button"
            aria-pressed={filter === f}
            onClick={() => setFilter(f)}
          >
            {f}
          </button>
        ))}
      </div>

      <ul>
        {shown.map((t) => (
          <li key={t.id}>
            <label>
              <input
                type="checkbox"
                checked={t.done}
                onChange={() => toggle(t.id)}
              />
              {t.title}
            </label>
          </li>
        ))}
      </ul>

      {shown.length === 0 && (
        <p>No assignments here.</p>
      )}

      <button type="button" onClick={clearDone}>
        Clear completed
      </button>
    </section>
  );
}

ReactDOM.createRoot(
  document.getElementById('root')
).render(<AssignmentTracker />);

KEY CONCEPTS

What This Exercise Demonstrates

1. Updating Objects in an Array

{ '{ ...t, done: !t.done }' } creates a copy of the selected task and changes its done property.

2. Array map()

map() creates a new array while updating the selected task.

3. Filtering with filter()

filter() creates a list containing only the assignments that match the selected status.

4. Derived State

The shown variable is calculated from tasks and filter. It does not need its own useState variable.

5. Conditional Rendering

The empty-state message appears when shown.length === 0.

Key takeaway: { '{ ...t, done: !t.done }' } copies the task and changes one field, so the original object is never modified. The filtered list is derived from state instead of stored separately.

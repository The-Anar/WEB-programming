E9 · Lab Profile Form

Manage multiple form inputs with one state object and validate the submitted information.

EXERCISE OVERVIEW

Challenge Description

Create a lab profile form with name and email fields. Store both input values in one React state object and validate the information when the form is submitted.

Requirements

  • Use one state object containing name and email.
  • Use one handleChange function for both inputs.
  • Use the input name attribute to identify the field being updated.
  • Require both name and email.
  • Validate the email address before accepting submission.
  • Display an appropriate error or success message.
  • Prevent the browser's default form submission.

IMPLEMENTATION

React Code

The profile object stores both form values. The handleChange function uses the input's name attribute to update the correct property. 

function LabProfile() {
  const [profile, setProfile] = useState({
    name: '',
    email: ''
  });

  const [message, setMessage] = useState('');

  function handleChange(e) {
    const { name, value } = e.target;

    setProfile({
      ...profile,
      [name]: value
    });
  }

  function handleSubmit(e) {
    e.preventDefault();

    if (!profile.name.trim() || !profile.email.trim()) {
      setMessage('Please fill in both fields.');
    } else if (!/^[^\s@]+@[^\s@]+$/.test(profile.email)) {
      setMessage('Please enter a valid email address.');
    } else {
      setMessage(
        `Thanks, ${profile.name.trim()}: profile submitted.`
      );
    }
  }

  return (
    <form onSubmit={handleSubmit} noValidate>
      <p>
        <label htmlFor="lab-name">Name </label>
        <input
          id="lab-name"
          name="name"
          type="text"
          value={profile.name}
          onChange={handleChange}
        />
      </p>

      <p>
        <label htmlFor="lab-email">Email </label>
        <input
          id="lab-email"
          name="email"
          type="email"
          value={profile.email}
          onChange={handleChange}
        />
      </p>

      <button type="submit">Submit profile</button>
      <p role="status">{message}</p>
    </form>
  );
}

ReactDOM.createRoot(
  document.getElementById('root')
).render(<LabProfile />);

KEY CONCEPTS

What This Exercise Demonstrates

1. One State Object

useState({ '{ name: "", email: "" }' }) stores multiple related input values in one object.

2. Computed Property Names

{ '{ [name]: value }' } uses the value of the variable name as the object property name. This allows the same handler to update either input.

3. Spread Syntax

{ '{ ...profile, [name]: value }' } copies the existing profile and replaces only the property being edited.

4. Form Validation

The submit handler checks that both fields are filled in and that the email matches the required basic pattern.

5. Preventing Default Submission

e.preventDefault() prevents the browser from reloading the page when the form is submitted.

Key takeaway: [name]: value is a computed key. The same handleChange function updates name or email, depending on which input changed.

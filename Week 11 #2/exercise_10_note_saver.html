E10 · Note Saver with useEffect

Save a note automatically using React useEffect and browser localStorage.

BATSUREN ANAR · STUDENT ID: 202637018

EXERCISE OVERVIEW

Challenge Description

Create a note-taking component that automatically saves its text to localStorage whenever the note changes. The saved note should remain available after reloading the page.

Requirements

  • Initialize the note state from localStorage.
  • Use a lazy initializer function with useState.
  • Use useEffect to save the note whenever it changes.
  • Use the storage key week11-note.
  • Provide a textarea for editing the note.
  • Provide a Clear note button.
  • Display a message depending on whether a note exists.
  • Handle cases where localStorage is unavailable.

IMPLEMENTATION

React Code

The lazy initializer reads the saved note when the component first renders. The effect then saves the updated note whenever the note state changes. 

function NoteSaver() {
  const [note, setNote] = useState(() => {
    try {
      return localStorage.getItem('week11-note') || '';
    } catch {
      return '';
    }
  });

  useEffect(() => {
    try {
      localStorage.setItem('week11-note', note);
    } catch {
      // Storage blocked: nothing saved.
    }
  }, [note]);

  return (
    <section>
      <label htmlFor="note">Note</label>
      <br />

      <textarea
        id="note"
        rows="4"
        cols="40"
        value={note}
        onChange={(e) => setNote(e.target.value)}
      />

      <br />

      <button
        type="button"
        onClick={() => setNote('')}
      >
        Clear note
      </button>

      <p aria-live="polite">
        {note
          ? 'Saved. Reload the page and it will still be here.'
          : 'No note yet.'}
      </p>
    </section>
  );
}

ReactDOM.createRoot(
  document.getElementById('root')
).render(<NoteSaver />);

KEY CONCEPTS

What This Exercise Demonstrates

1. Lazy State Initialization

useState(() => ...) uses a function to initialize the state. React calls this initializer when the component is first rendered.

2. useEffect

useEffect() runs after rendering. With [note] as its dependency array, the effect runs when the note value changes.

3. localStorage

localStorage.setItem() stores the note in the browser. localStorage.getItem() retrieves it later, including after a page reload.

4. Controlled Textarea

The textarea uses value={note} and onChange to keep its displayed text synchronized with React state.

5. Error Handling

The try/catch blocks prevent storage errors from breaking the component if browser storage is blocked.

Key takeaway: The function passed to useState runs only during initialization, so localStorage is not read on every keystroke. The useEffect saves the note whenever its state changes.

EXERCISE OVERVIEW

Challenge Description

Build a live card editor with two input fields. The title and text values should update a reusable Card component immediately as the user types.

Requirements

  • Create a reusable Card component.
  • Accept the title through a title prop.
  • Render the card content through children.
  • Use controlled inputs for the title and text.
  • Initialize the title as My card.
  • Initialize the text as Edit me above..
  • Update the preview immediately when either input changes.
  • Display Untitled when the title is empty.

IMPLEMENTATION

React Code

The CardEditor component manages the title and text with separate state variables. It passes the title as a prop and the text as children to the reusable Card component. 

function Card({ title, children }) {
  return (
    <section>
      <h2>{title || 'Untitled'}</h2>
      {children}
    </section>
  );
}

function CardEditor() {
  const [title, setTitle] = useState('My card');
  const [text, setText] = useState('Edit me above.');

  return (
    <div>
      <p>
        <label htmlFor="card-title">Title </label>
        <input
          id="card-title"
          type="text"
          value={title}
          onChange={(e) => setTitle(e.target.value)}
        />
      </p>

      <p>
        <label htmlFor="card-text">Text </label>
        <input
          id="card-text"
          type="text"
          value={text}
          onChange={(e) => setText(e.target.value)}
        />
      </p>

      <Card title={title}>
        <p style={{ margin: 0 }}>{text}</p>
      </Card>
    </div>
  );
}

ReactDOM.createRoot(
  document.getElementById('root')
).render(<CardEditor />);

KEY CONCEPTS

What This Exercise Demonstrates

1. Controlled Inputs

Each input uses a state value and an onChange handler. React state controls what appears inside the input.

2. Reusable Components

The Card component can be reused with different titles and content.

3. Passing Props

title={title} passes the current title value from CardEditor into the Card component.

4. The children Prop

Content placed between the opening and closing Card tags becomes the component's children prop.

5. Live Updates

When either state value changes, React re-renders the component and updates the card preview.

Key takeaway: Two controlled inputs feed the reusable Card component through props and children, so the preview updates as you type.

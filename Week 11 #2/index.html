WHAT I LEARNED

Learning Objectives

React State

Understand how useState stores and updates information inside functional components.

Events & Interactions

Handle user actions with event handlers such as onClick and onChange.

Controlled Inputs

Connect form inputs to React state and update values as users type.

Updating Arrays & Objects

Use spread syntax, map(), and filter() to update state without directly modifying existing data.

Conditional Rendering

Display different content depending on the current state of a component.

Effects & Local Storage

Use useEffect to synchronize React state with browser storage.

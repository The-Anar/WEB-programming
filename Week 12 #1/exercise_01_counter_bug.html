Week 12 · Exercise 01

Counter Bug

Discover why regular JavaScript variables do not automatically update the React user interface.

BATSUREN ANAR · STUDENT ID: 202637018

1. Exercise Objective

In this exercise, we explore what happens when a counter uses a regular JavaScript variable instead of React state.

  • Create a regular variable named count.
  • Increase its value when a button is clicked.
  • Observe the value in the console.
  • Notice that the displayed number does not update automatically.

2. The Counter Bug

function CounterBug() {
    let count = 0;

    function increase() {
        count++;
        console.log(count);
    }

    return (
        <div>
            <h2>Count: {count}</h2>
            <button onClick={increase}>
                Increase
            </button>
        </div>
    );
}
The variable changes when the button is clicked, but React does not know that it should render the component again.

4. Why Does This Happen?

  1. The component starts with count = 0.
  2. The user clicks the button.
  3. JavaScript increases the regular variable.
  4. The new value is logged to the console.
  5. React does not receive a state update, so it does not re-render.
React needs state to remember changing values and trigger UI updates.

5. How to Fix It

Use useState instead of a regular variable:

function Counter() {
    const [count, setCount] = React.useState(0);

    function increase() {
        setCount(count + 1);
    }

    return (
        <div>
            <h2>Count: {count}</h2>
            <button onClick={increase}>
                Increase
            </button>
        </div>
    );
}

6. Key Takeaways

  • Regular variables do not trigger React re-renders.
  • React does not automatically track changes to ordinary variables.
  • The console can show a changing value while the UI remains unchanged.
  • useState allows React to remember values between renders.
  • Use a state setter whenever a change should update the UI.

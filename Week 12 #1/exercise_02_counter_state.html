Counter with State

Use React's useState hook to create a counter that updates the interface whenever its value changes.

BATSUREN ANAR · STUDENT ID: 202637018

1. Exercise Objective

In this exercise, we use the useState hook to manage a counter.

  • Increase the counter by one.
  • Decrease the counter by one.
  • Reset the counter to zero.
  • Compare normal state updates with functional updates.

2. Basic useState Counter

function Counter() {
    const [count, setCount] = React.useState(0);

    function increase() {
        setCount(count + 1);
    }

    function decrease() {
        setCount(count - 1);
    }

    function reset() {
        setCount(0);
    }

    return (
        <div>
            <h2>Count: {count}</h2>
            <button onClick={increase}>+</button>
            <button onClick={decrease}>-</button>
            <button onClick={reset}>Reset</button>
        </div>
    );
}

4. Normal Update vs Functional Update

Sometimes, we want to update state several times in one event. Compare these two approaches.

Normal update

setCount(count + 1);
setCount(count + 1);
setCount(count + 1);

These updates use the same current value. React batches them, so the result is usually only +1.

Functional update

setCount(c => c + 1);
setCount(c => c + 1);
setCount(c => c + 1);

Each update receives the latest pending value, so the result is +3.

Use functional updates when the next state depends on the previous state.

6. Key Takeaways

  • useState creates a state variable and a setter function.
  • Calling the setter tells React to render the component again.
  • State updates can be batched by React.
  • Functional updates use the previous state value.
  • Use setCount(previous => previous + 1) when the next value depends on the previous value.

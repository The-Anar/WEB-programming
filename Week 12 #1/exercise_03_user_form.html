Week 12 · Exercise 03

User Form

Build an interactive form using multiple React state variables to manage user information.

BATSUREN ANAR · STUDENT ID: 202637018

1. Exercise Objective

This exercise demonstrates how one React component can manage several independent pieces of state.

  • Manage a name field.
  • Manage an email field.
  • Manage an age field.
  • Submit the form and display the entered information.
  • Return to editing after submission.

2. Multiple State Variables

function UserForm() {
    const [name, setName] = React.useState("");
    const [email, setEmail] = React.useState("");
    const [age, setAge] = React.useState("");
    const [submitted, setSubmitted] = React.useState(false);

    function handleSubmit(event) {
        event.preventDefault();
        setSubmitted(true);
    }

    return (
        <form onSubmit={handleSubmit}>
            <input
                value={name}
                onChange={e => setName(e.target.value)}
            />
            <input
                value={email}
                onChange={e => setEmail(e.target.value)}
            />
            <input
                value={age}
                onChange={e => setAge(e.target.value)}
            />
            <button type="submit">Submit</button>
        </form>
    );
}
Each useState call manages one independent value. Updating one field does not require changing the others.

4. Controlled Components

Each input is a controlled component because React state controls its value.

<input
    value={name}
    onChange={event => setName(event.target.value)}
/>
  • value displays the current state value in the input.
  • onChange detects when the user types.
  • setName updates the state and refreshes the interface.

5. Key Takeaways

  • A component can use multiple useState hooks.
  • Each state variable can manage a separate form field.
  • Controlled inputs use both value and onChange.
  • event.preventDefault() prevents the browser's default form submission.
  • State updates automatically refresh the React interface.

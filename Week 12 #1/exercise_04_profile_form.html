Week 12 · Exercise 04

Profile Form

Manage a user's profile information with a single object state and update individual properties without losing other values.

BATSUREN ANAR · STUDENT ID: 202637018

1. Exercise Objective

Instead of creating separate state variables for every field, we can store related information inside one JavaScript object.

  • Create one profile object with name, email, and bio.
  • Update individual properties using the spread operator.
  • Keep the other properties unchanged.
  • Display the current profile and its JSON state.

2. Object State

function ProfileForm() {
    const [profile, setProfile] = React.useState({
        name: "",
        email: "",
        bio: ""
    });

    function updateField(field, value) {
        setProfile({
            ...profile,
            [field]: value
        });
    }

    return (
        <input
            value={profile.name}
            onChange={e =>
                updateField("name", e.target.value)
            }
        />
    );
}
The spread operator ...profile copies the existing properties. The new value replaces only the property being edited.

4. Why Use the Spread Operator?

Incorrect update

setProfile({
    name: "Anar"
});

This replaces the entire object. The previous email and bio properties are lost.

Correct update

setProfile({
    ...profile,
    name: "Anar"
});

This keeps the existing properties and changes only the name.

5. Dynamic Property Updates

We can use a computed property name to update different fields with one function.

function updateField(field, value) {
    setProfile(previousProfile => ({
        ...previousProfile,
        [field]: value
    }));
}

For example, updateField("email", "hello@example.com") updates the email property while preserving the other fields.

6. Key Takeaways

  • Objects can store related information in one state variable.
  • React state should be updated immutably.
  • The spread operator copies existing object properties.
  • Computed property names allow reusable update functions.
  • Functional updates are useful when the next state depends on the previous state.

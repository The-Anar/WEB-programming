Todo List

Manage a list of tasks using React array state. Add, complete, and delete tasks dynamically.

BATSUREN ANAR · STUDENT ID: 202637018

1. Exercise Objective

This exercise demonstrates how React manages arrays inside state.

  • Add new tasks using the spread operator.
  • Remove tasks using filter().
  • Toggle completed tasks using map().
  • Calculate the number of remaining tasks.

2. Array State

function TodoList() {
    const [todos, setTodos] = React.useState([]);

    function addTodo(text) {
        setTodos(previous => [
            ...previous,
            { id: Date.now(), text, completed: false }
        ]);
    }

    function deleteTodo(id) {
        setTodos(previous =>
            previous.filter(todo => todo.id !== id)
        );
    }

    function toggleTodo(id) {
        setTodos(previous =>
            previous.map(todo =>
                todo.id === id
                    ? { ...todo, completed: !todo.completed }
                    : todo
            )
        );
    }
}
React state arrays should be updated by creating a new array instead of directly modifying the existing one.

4. Important Array Methods

map()

todos.map(todo => ({
    ...todo,
    completed: true
}));

Creates a new array by transforming each item. Useful for updating a task.

filter()

todos.filter(todo =>
    todo.id !== targetId
);

Creates a new array containing only matching items. Useful for deleting a task.

5. Key Takeaways

  • Arrays can be stored in React state.
  • The spread operator adds items without mutating the original array.
  • map() can update individual array items.
  • filter() can remove items from an array.
  • React re-renders when the state setter receives a new array.

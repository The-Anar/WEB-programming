Search Page

Learn how to lift state up so multiple React components can share and use the same data.

1. Exercise Objective

In this exercise, we create a search page with three components:

  • SearchPage: The parent component that owns the search state.
  • SearchBar: A child component where the user enters a search term.
  • ResultList: A child component that displays matching results.

The parent shares data and functions with its children using props.

2. What Is Lifting State Up?

When multiple components need the same information, we move that state to their closest common parent.

function SearchPage() {
    const [query, setQuery] = useState("");
    const [results, setResults] = useState([]);

    function handleSearch(searchTerm) {
        const filtered = FRUITS.filter(fruit =>
            fruit.toLowerCase().includes(
                searchTerm.toLowerCase()
            )
        );
        setResults(filtered);
    }

    return (
        <>
            <SearchBar onSearch={handleSearch} />
            <ResultList results={results} />
        </>
    );
}
The parent owns the state. The children receive the information and functions they need through props.

3. Component Structure

SearchPage (Parent)
│
├── SearchBar (Child)
│   └── Receives onSearch function
│
└── ResultList (Child)
    └── Receives results array

SearchBar sends the search term to its parent. SearchPage updates its state and passes the matching results to ResultList.

5. How Props Connect Components

Passing a function

<SearchBar
    onSearch={handleSearch}
/>

The parent passes a function to the SearchBar child.

Passing data

<ResultList
    results={results}
/>

The parent passes the search results to the ResultList child.

6. Key Takeaways

  • Lifting state up means moving state to a common parent component.
  • The parent becomes the owner of shared data.
  • Props allow a parent to pass data to child components.
  • Callback functions allow children to communicate events to their parent.
  • Sharing state this way keeps related components synchronized.

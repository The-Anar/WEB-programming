Week 12 · Exercise 07

Counter with History

Build a counter that remembers previous values and allows users to undo their last action.

BATSUREN ANAR · STUDENT ID: 202637018

1. Exercise Objective

This exercise combines React state and array manipulation to create a counter with an undo feature.

  • Increase and decrease the counter.
  • Reset the counter to zero.
  • Store previous counter values in an array.
  • Undo the most recent change.
  • Display the last five history entries.

2. Multiple State Variables

function CounterWithHistory() {
    const [count, setCount] = React.useState(0);
    const [history, setHistory] = React.useState([0]);

    function updateCount(newValue) {
        setCount(newValue);
        setHistory(previous => [
            ...previous,
            newValue
        ]);
    }
}

The counter stores its current value, while the history array stores the sequence of values.

3. Undo Function

function undo() {
    if (history.length <= 1) return;

    const previousHistory = history.slice(0, -1);
    const previousValue =
        previousHistory[previousHistory.length - 1];

    setHistory(previousHistory);
    setCount(previousValue);
}
The slice() method creates a new array without its last item. The previous value becomes the current counter value.

5. Important Concepts

Array history

setHistory(previous => [
    ...previous,
    newValue
]);

The spread operator creates a new array and adds the latest value.

Undo with slice()

const previous =
    history.slice(0, -1);

Creates a copy of the history without its latest entry.

6. Key Takeaways

  • Multiple state variables can work together in one component.
  • Arrays can store a sequence of previous state values.
  • Functional updates safely create new history arrays.
  • slice() can remove the latest history entry without mutating the original array.
  • Undo restores the previous value by reading the history array.

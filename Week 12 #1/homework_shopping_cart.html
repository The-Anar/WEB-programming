Interactive Shopping Cart

Build a shopping cart using React state, props, arrays, and component communication.

1. Assignment Objectives

Create an interactive shopping cart where users can browse products and manage their purchases.

  • Display products with names, images, and prices.
  • Add products to the shopping cart.
  • Increase or decrease product quantities.
  • Remove products from the cart.
  • Calculate the total price automatically.
  • Use React state and props to share data between components.

2. Component Architecture

App
 └── ShoppingCart
      ├── ProductList
      │    └── ProductCard
      └── Cart
           └── CartItem

ShoppingCart owns the cart state. ProductList and Cart receive data and callback functions through props.

4. Important React Concepts

Array State

const [cart, setCart] =
    useState([]);

The cart is stored as an array of product objects.

Adding Products

setCart(previous => [
    ...previous,
    newItem
]);

The spread operator creates a new array with the added item.

Updating Quantity

setCart(previous =>
    previous.map(item =>
        item.id === id
        ? {...item, quantity: item.quantity + 1}
        : item
    )
);

The map method updates only the matching product.

Calculating Total

const total = cart.reduce(
    (sum, item) =>
        sum + item.price * item.quantity,
    0
);

The reduce method calculates the total price of all cart items.

5. Conclusion

This project demonstrates how React state and props can be used to build an interactive shopping application.

  • State manages the shopping cart data.
  • Props pass products and callback functions between components.
  • Array methods update and remove cart items.
  • Reduce calculates the total price from the current cart.

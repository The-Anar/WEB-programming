What Is State?

Understanding the difference between State and Props in React.

BATSUREN ANAR · STUDENT ID: 202637018

1. What Is State?

State is data that a React component remembers and manages by itself. It allows a component to keep information between renders and update its user interface when that information changes.

For example, a counter needs to remember its current number. A form needs to remember what the user has typed. State makes these updates possible.

When state changes, React re-renders the component so the screen can display the updated information.

2. State vs Props

State

State is data owned and managed by a component.

  • Managed inside the component.
  • Can change over time.
  • Updated using a state setter.
  • Changing state causes a re-render.

Props

Props are data passed from a parent component to a child component.

  • Received from a parent component.
  • Read-only inside the child.
  • Used to customize child components.
  • New props can cause a re-render.

3. Understanding State in Code

Here is a simple React counter using state:

function Counter() {
    const [count, setCount] = React.useState(0);

    function increase() {
        setCount(count + 1);
    }

    return (
        <div>
            <h2>Count: {count}</h2>
            <button onClick={increase}>
                Increase
            </button>
        </div>
    );
}

count stores the current value. setCount updates that value. useState(0) sets the initial value to zero.

4. Why Regular Variables Do Not Work

A regular JavaScript variable does not tell React when its value changes. React also does not preserve that variable's value between renders. 

function Counter() {
    let count = 0;

    function increase() {
        count = count + 1;
        console.log(count);
    }

    return (
        <button onClick={increase}>
            Count: {count}
        </button>
    );
}
The console may show an increasing number, but the displayed button stays at zero. React does not know that the regular variable changed.

6. Key Takeaways

  • State is data that a component remembers and manages.
  • Props are passed from a parent component to a child.
  • State changes trigger a React re-render.
  • Props should not be directly modified by the receiving component.
  • Regular variables do not provide React with persistent, reactive state.
  • Use useState when a component needs to remember changing data.

useState Syntax & Rules of Hooks

Learn how to create, read, and update state in React.

BATSUREN ANAR · STUDENT ID: 202637018

1. What Is useState?

useState is a React Hook that allows a function component to remember information between renders.

It returns two things: the current state value and a function that updates that value.

When you update state using its setter function, React schedules a re-render so the user interface can show the new value.

2. useState Syntax

import { useState } from "react";

function Counter() {
    const [count, setCount] = useState(0);

    return (
        <div>
            <p>Count: {count}</p>
            <button onClick={() => setCount(count + 1)}>
                Increase
            </button>
        </div>
    );
}

The three important parts are:

  • count — the current state value.
  • setCount — the function used to update the state.
  • useState(0) — initializes the state with the value 0.

3. How the Setter Works

Read the state

const [count, setCount] = useState(0);

console.log(count);

The variable contains the current state value for this render.

Update the state

setCount(count + 1);

The setter requests a state update and React re-renders the component.

4. Initial State Values

State can store different types of JavaScript values.

const [name, setName] = useState("Anar");
const [age, setAge] = useState(22);
const [isOnline, setIsOnline] = useState(true);
const [items, setItems] = useState([]);
const [user, setUser] = useState({
    name: "Anar",
    email: "anar@example.com"
});

Common initial values include:

  • String: "Anar"
  • Number: 0
  • Boolean: true or false
  • Array: []
  • Object: { name: "Anar" }

5. Rules of Hooks

React Hooks must follow specific rules to work correctly.

Rule 1 — Call Hooks at the Top Level

Do not call Hooks inside loops, conditions, or nested functions.

// Correct
function Counter() {
    const [count, setCount] = useState(0);

    if (count > 5) {
        console.log("More than five");
    }

    return <p>{count}</p>;
}
// Incorrect
function Counter() {
    if (true) {
        const [count, setCount] = useState(0);
    }
}

Rule 2 — Only Call Hooks from React Functions

Call Hooks inside React function components or custom Hooks, not ordinary JavaScript functions.

Rule 3 — Keep Hook Calls in the Same Order

React relies on the order of Hook calls to keep track of each component's state.

Remember: Hooks should be called at the top level of a component, before conditional returns.

7. Key Takeaways

  • useState is a React Hook for storing component state.
  • It returns the current state and a setter function.
  • The initial value is passed to useState().
  • Use the setter function to request state updates.
  • Hooks must be called at the top level of React components or custom Hooks.
  • Do not call Hooks inside conditions, loops, or nested functions.
  • Keep Hook calls in a consistent order between renders.

Updating State Correctly

Learn how to update React state without mutating existing data.

BATSUREN ANAR · STUDENT ID: 202637018

1. Why State Updates Matter

React state should be treated as immutable. This means you should not directly change the current state value. Instead, create a new value and pass it to the setter function.

Use the state setter to update state. Do not modify the existing state directly.

2. Direct Mutation vs Correct Updates

Incorrect: Direct Mutation

let [count, setCount] = useState(0);

// Do not do this
count = count + 1;

Changing the variable directly does not tell React to update the component.

Correct: Use the Setter

const [count, setCount] = useState(0);

function increase() {
    setCount(count + 1);
}

The setter schedules a state update and React can render the new value.

3. Functional State Updates

Sometimes the next state depends on the previous state. In that situation, use the functional update form.

setCount(previousCount => previousCount + 1);

The function receives the previous state and returns the next state.

Functional updates are especially useful when multiple updates happen in the same event or when updates depend on the latest state.

4. Understanding React Batching

React can group multiple state updates together. Each render sees a snapshot of state. Calling the setter with count + 1 repeatedly in the same handler can use the same old value.

Value-based updates

function addThree() {
    setCount(count + 1);
    setCount(count + 1);
    setCount(count + 1);
}

These updates may result in only +1.

Functional updates

function addThree() {
    setCount(prev => prev + 1);
    setCount(prev => prev + 1);
    setCount(prev => prev + 1);
}

Each update receives the previous queued value, resulting in +3.

6. Important Rules

  • Never directly modify a state variable.
  • Always use its setter function.
  • Use functional updates when the next value depends on the previous value.
  • React may batch multiple updates together.
  • State values belong to a particular render and behave like snapshots.
  • Return a new value instead of mutating existing state.

7. Key Takeaways

  • setCount(count + 1) updates state using the value from the current render.
  • setCount(prev => prev + 1) calculates the next state from the previous state.
  • Three value-based updates can produce only +1.
  • Three functional updates produce +3.
  • Immutable updates help React detect changes correctly.

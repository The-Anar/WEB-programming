Multiple State Variables

Learn how to manage different pieces of information using multiple useState calls.

BATSUREN ANAR · STUDENT ID: 202637018

1. Why Use Multiple State Variables?

A React component often needs to remember several different values. For example, a form may need to store a user's name, email address, age, and whether the form has been submitted.

You can create a separate useState call for each value.

Each state variable has its own value and its own setter function.

2. Creating Multiple State Variables

function UserForm() {
    const [name, setName] = useState("");
    const [email, setEmail] = useState("");
    const [age, setAge] = useState("");
    const [submitted, setSubmitted] = useState(false);

    return (
        <div>
            <input value={name}
                onChange={e => setName(e.target.value)} />

            <input value={email}
                onChange={e => setEmail(e.target.value)} />

            <input value={age}
                onChange={e => setAge(e.target.value)} />
        </div>
    );
}

Here, each piece of information is stored independently.

3. Controlled Inputs

A controlled input is an input whose value is managed by React state.

const [name, setName] = useState("");

<input
    value={name}
    onChange={event => setName(event.target.value)}
/>
  • value displays the current state value.
  • onChange runs when the user types.
  • setName updates the state with the new input value.

4. Handling Form Submission

function handleSubmit(event) {
    event.preventDefault();
    setSubmitted(true);
}

event.preventDefault() prevents the browser's default form submission behavior, allowing React to handle the form.

After submission, you can display a confirmation message or a summary of the entered information.

6. Key Takeaways

  • A component can use multiple useState calls.
  • Each state variable can represent a different piece of information.
  • Use separate setter functions to update separate values.
  • Controlled inputs use value and onChange.
  • Use event.preventDefault() to prevent the browser's default form submission.
  • Use conditional rendering to show different content after submission.

State with Objects & Arrays

Learn how to manage complex data using objects and arrays in React state.

BATSUREN ANAR · STUDENT ID: 202637018

1. State with Objects

Objects allow you to group related information into one state variable.

const [profile, setProfile] = useState({
    name: "Anar",
    email: "anar@example.com",
    age: 22
});

Instead of creating separate state variables, you can keep related profile information together.

2. Updating Objects Correctly

Never change an existing state object directly. Create a new object using the spread operator.

// Incorrect
profile.name = "Alex";
setProfile(profile);

// Correct
setProfile(prev => ({
    ...prev,
    name: "Alex"
}));
The spread operator ... copies the existing properties. Then the new value replaces the property you want to change.

3. Updating a Dynamic Object Property

You can use a variable as the property name with computed property syntax.

function handleChange(event) {
    const { name, value } = event.target;

    setProfile(prev => ({
        ...prev,
        [name]: value
    }));
}

This pattern is useful when several form inputs update different properties of the same object.

4. State with Arrays

Arrays are useful when a component needs to store a list of items, such as tasks, products, or messages.

const [todos, setTodos] = useState([
    "Study React",
    "Complete homework"
]);

When updating an array, create a new array instead of changing the original one.

5. Common Array Updates

Add an item

setTodos(prev => [
    ...prev,
    "New task"
]);

Remove an item

setTodos(prev =>
    prev.filter((todo, index) =>
        index !== removeIndex
    )
);

Update an item

setTodos(prev =>
    prev.map(todo =>
        todo === "Study React"
            ? "Practice React"
            : todo
    )
);

What to avoid

// Avoid direct mutation
todos.push("New task");
todos.splice(0, 1);

8. Key Takeaways




    

  • Objects group related information into one state variable.
    • 

  • Use the spread operator to copy existing object properties.
    • 

  • Use computed property names to update dynamic object fields.
    • 

  • Arrays store collections of data.
    • 

  • Use map() to update array items.
    • 

  • Use filter() to remove array items.
    • 

  • Use the spread operator to add new array items.
    • 

  • Avoid direct mutation methods such as push() and splice() on state arrays.

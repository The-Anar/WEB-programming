Lifting State Up

Learn how to share state between components using a common parent component.

BATSUREN ANAR · STUDENT ID: 202637018

1. What Is Lifting State Up?

Lifting state up means moving shared state from child components into their nearest common parent component.

When multiple components need the same information, keeping separate copies of that information can cause problems.

The parent owns the shared state and passes the data to children through props.

2. Why Do We Need It?

Without Lifting State

Two child components keep their own separate copies of the same information.

  • Values can become inconsistent.
  • Components may show different information.
  • Sharing updates becomes difficult.

With Lifting State

The parent stores one shared state value and gives it to both children.

  • One source of truth.
  • Children stay synchronized.
  • Updates are easier to manage.

3. How Data Flows

Parent → Child → Parent

function Parent() {
    const [count, setCount] = useState(0);

    return (
        <div>
            <Display count={count} />
            <CounterButton
                onIncrease={() => setCount(count + 1)}
            />
        </div>
    );
}

The parent passes the current value down as a prop and passes a callback function down so the child can request an update.

Data flows down through props. Events and update requests flow up through callback functions.

4. Child Components Receive Props

Display Component

function Display({ count }) {
    return <h2>Count: {count}</h2>;
}

The child receives the count value from its parent.

Button Component

function CounterButton({ onIncrease }) {
    return (
        <button onClick={onIncrease}>
            Increase
        </button>
    );
}

The child calls the callback when the user clicks the button.

6. Example: Search Components

Imagine a search page with three components:

  • SearchPage: owns the search query and results.
  • SearchBar: accepts user input and sends the search request to its parent.
  • ResultList: receives and displays results from its parent.
function SearchPage() {
    const [query, setQuery] = useState("");
    const [results, setResults] = useState([]);

    function handleSearch(value) {
        setQuery(value);
        // Update results here
    }

    return (
        <>
            <SearchBar onSearch={handleSearch} />
            <ResultList results={results} />
        </>
    );
}

7. Key Takeaways

  • Lift state up when multiple components need the same data.
  • Move shared state into the nearest common parent.
  • Pass state values down through props.
  • Pass callback functions down to allow children to request updates.
  • The parent becomes the single source of truth.
  • Data flows down, while events flow up through callbacks.

Frequently Asked Questions

What is the difference between section and article?

An article is self-contained and can make sense outside its page, such as a blog post. A section groups related content that belongs to a larger page.

Why should I use semantic HTML?

Semantic HTML improves: (1) SEO — search engines can better understand page structure; (2) Accessibility — screen readers can navigate page landmarks; (3) Maintainability — code is easier for developers to read.

Key rule to remember

Use semantic elements whenever they fit the content. Use div or span when no suitable semantic element applies.

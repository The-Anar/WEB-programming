Understanding CSS Flexbox

CSS Flexbox is a layout model that allows you to design complex layouts with ease.
It provides a more efficient way to align and distribute space among items in a container, even when their size is unknown or dynamic.

Learning HTML and CSS

HTML is used to structure the content of a web page, while CSS is used to control its appearance.

CSS Flexbox helps arrange elements in a row or column and makes it easier to create flexible layouts.

Quick Reference

display: flex — activates Flexbox

flex-direction: row — arranges items horizontally

justify-content: center — centres items along the main axis

The align-items property controls how items are aligned along the cross axis.

Interactive Validation Form

Type into each field to see the border and background change automatically.

CSS Rules Used

input:valid:not(:placeholder-shown) {
    border-color: #23945F;
    background: #F0FFF7;
}

input:invalid:not(:placeholder-shown) {
    border-color: #D64545;
    background: #FFF3F3;
}

input:focus {
    outline: 2px solid #B8A4F0;
}

Exercise Checklist

  • Valid fields display a green border after typing.
  • Invalid fields display a red border after typing.
  • Focused fields display an outline.
  • Required fields and input patterns use browser validation.

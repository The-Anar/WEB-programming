Topic 01 — Why Forms?

Web Programming · Gachon University · Anar

What is an HTML form?

An HTML form collects information from users. Examples include login forms, search boxes, and student registration forms.

Example: A simple search form

Key points

  • Forms collect information from users.
  • The <form> element contains form controls.
  • The action attribute specifies where data is sent.
  • The method attribute specifies how data is sent.

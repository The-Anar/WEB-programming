Topic 02 — The <form> Element

Web Programming · Gachon University · Anar

GET vs. POST

GET: Sends form data in the URL. Useful for search.

POST: Sends form data in the request body. Common for submitting information.

Live Form Demo

Submitting sends the value through Google's search URL using GET.

Important Attributes

  • action — destination for submitted data.
  • method — specifies GET or POST.
  • name — identifies a submitted field.
  • type="submit" — submits the form.

Try Different Input Types

Years of coding: 3

Checkboxes — Multiple choices

Radio buttons — Choose one

Key Points

  • text accepts ordinary text.
  • email supports email-format validation.
  • password masks typed characters.
  • number, date, and range provide specialized controls.
  • Checkboxes allow multiple selections; radio buttons allow one selection per group.
  • select creates a dropdown menu.

Validation Attributes

  • required — prevents empty required fields.
  • minlength and maxlength — set text length limits.
  • min and max — set numeric limits.
  • step — sets allowed numeric increments.
  • pattern — requires a value matching a specified pattern.
  • title — provides a helpful hint for pattern validation.
  • type="email" — checks email format.

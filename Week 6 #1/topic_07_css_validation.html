CSS Pseudo-classes

  • :valid selects inputs that satisfy their validation rules.
  • :invalid selects inputs that do not satisfy their validation rules.
  • :not(:placeholder-shown) selects inputs where the placeholder is no longer shown.
  • :focus styles the input currently selected by the user.

CSS Used

input:valid:not(:placeholder-shown) {
    border-color: #23945F;
}

input:invalid:not(:placeholder-shown) {
    border-color: #D64545;
}

input:focus {
    outline: 2px solid #B8A4F0;
}

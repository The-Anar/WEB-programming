CSS Layout & Cards

Use CSS Grid to make cards adapt to the available width. Keep each cover, title, author, and year inside a consistent card.

Code sample

.book-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(210px, 1fr));
  gap: 15px;
}
.book { display: flex; flex-direction: column; }
.cover { height: 220px; display: grid; place-items: center; }
.book-info { padding: 14px; }

Checklist

  • Use repeat(auto-fit, minmax(...)) for responsive cards.
  • Keep cover images within a predictable area.
  • Test both narrow and wide screens.

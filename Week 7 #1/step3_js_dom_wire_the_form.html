Wire the Form with DOM

Select the form and input, listen for submit, and prevent the browser's default page reload.

BATSUREN ANAR · STUDENT ID: 202637018

Code sample

const form = document.querySelector("#search-form");
const input = document.querySelector("#book-query");

form.addEventListener("submit", event => {
  event.preventDefault();
  const query = input.value.trim();
  console.log(query);
});

Checklist

  • Use querySelector() to find elements.
  • Call event.preventDefault() on submit.
  • Trim the search text before using it.

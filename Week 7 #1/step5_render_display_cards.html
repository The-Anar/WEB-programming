Code sample

const books = data.docs || [];
results.innerHTML = books.map(book => `
  <article class="book">
    <div class="book-info">
      <h3>${book.title || "Untitled book"}</h3>
      <p>${book.author_name?.[0] || "Author unknown"}</p>
      <p>${book.first_publish_year || "Year unknown"}</p>
    </div>
  </article>
`).join("");

Checklist

  • Read title, author_name and first_publish_year.
  • Use cover_i with the Open Library Covers service.
  • Escape text before inserting untrusted data into HTML.

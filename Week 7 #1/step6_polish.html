Polish: Loading & Errors

Give users feedback while the request is running, when no books match, and when a network request fails.

BATSUREN ANAR · STUDENT ID: 202637018

Code sample

status.textContent = "Searching…";
try {
  const response = await fetch(apiUrl);
  if (!response.ok) throw new Error("Request failed");
  const data = await response.json();
  status.textContent = data.docs.length
    ? "Books loaded."
    : "No books found. Try another search.";
} catch (error) {
  status.textContent = "Couldn't load books. Try again.";
}

Checklist

  • Show a loading message before fetching.
  • Handle empty results separately from network errors.
  • Use aria-live status feedback.

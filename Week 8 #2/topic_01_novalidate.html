Topic 01 — novalidate

Control native browser form validation and build custom feedback with JavaScript.

BATSUREN ANAR · STUDENT ID: 202637018

1. What is novalidate?

Normally, HTML forms use built-in browser validation. For example, a required field cannot be empty, and an email field must contain a valid email address.

The novalidate attribute disables these automatic browser validation popups when a form is submitted. 

<form novalidate>
    <input type="email" required>
    <button type="submit">Submit</button>
</form>

This allows JavaScript to take control of validation and display our own error messages.

2. Why is it useful?

  • We can create our own validation messages.
  • We can control when errors appear.
  • We can provide more helpful instructions to users.
  • We can build a consistent form design instead of relying only on browser popups.

Important: novalidate does not remove the browser's Validity API. JavaScript can still use checkValidity() to check whether the form fields are valid.

4. How does the JavaScript work?

const form = document.getElementById('custom-form');
const email = document.getElementById('custom-email');

form.addEventListener('submit', function(event) {
    event.preventDefault();

    if (!email.checkValidity()) {
        document.getElementById('email-error').textContent =
            'Please enter a valid email address.';

        return;
    }

    document.getElementById('email-error').textContent = '';

    document.getElementById('custom-result').textContent =
        'Success! Your email is valid.';
});
  • novalidate disables automatic submission popups.
  • preventDefault() stops the normal form submission.
  • checkValidity() checks the field's validity.
  • JavaScript displays our own validation message.

5. Remember

  • novalidate disables automatic browser validation during form submission.
  • It does not disable the Validity API.
  • checkValidity() can still check form fields.
  • Use JavaScript to provide clear custom feedback.
  • Always validate data before processing it.

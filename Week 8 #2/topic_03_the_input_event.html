Topic 03 — The input Event

Use the input event to respond to changes immediately while a user types into a form field.

Week 8 Home Previous Topic Next Topic

What is the input event?

The input event fires whenever the value of an input field changes. For example, it happens when a user types, deletes, or pastes text into a text field.

Unlike the change event, which usually fires after the user finishes editing a field and moves away from it, the input event responds immediately.

Why is it useful?

  • Show feedback while the user is typing.
  • Update character counts in real time.
  • Preview information before submitting a form.
  • Help users correct mistakes earlier.

Code example

The addEventListener() method connects the input event to a function. The function runs whenever the field's value changes. 

const nameInput = document.getElementById('student-name');

nameInput.addEventListener('input', function() {
    const value = nameInput.value;

    console.log('Current value:', value);
});

Remember

  • The input event runs whenever the field value changes.
  • It is useful for real-time feedback.
  • Use event.target.value or the input element's value to read the current text.
  • The input event does not automatically submit a form.

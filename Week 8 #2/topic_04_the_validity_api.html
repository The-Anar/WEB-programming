What is the Validity API?

The Constraint Validation API provides properties and methods that help JavaScript check whether a form field satisfies its validation rules.

Every input element has a validity property. It contains information about the field's current validation state.

Important validity properties

  • valueMissing: The field is required but empty.
  • typeMismatch: The value does not match the input type, such as an invalid email.
  • tooShort: The value is shorter than the minlength requirement.
  • tooLong: The value exceeds the maxlength requirement.
  • patternMismatch: The value does not match the specified pattern.
  • valid: The field satisfies all its validation constraints.

The checkValidity() method returns true if the element satisfies its constraints, and false if it does not.

Code example

The validity property lets us inspect individual validation conditions. checkValidity() checks whether all constraints are satisfied. 

const email = document.getElementById('email');

if (email.validity.valueMissing) {
    console.log('Email is required.');
} else if (email.validity.typeMismatch) {
    console.log('Enter a valid email address.');
} else if (email.checkValidity()) {
    console.log('Email is valid.');
}

Remember

  • The validity property provides details about validation errors.
  • valueMissing checks required fields.
  • typeMismatch checks values such as email addresses.
  • patternMismatch checks values against a regular expression pattern.
  • checkValidity() returns true or false.

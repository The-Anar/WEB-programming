Topic 05 — setCustomValidity()

Create custom validation messages when built-in HTML validation rules are not enough.

Week 8 Home Previous Topic Next Topic

What is setCustomValidity()?

The setCustomValidity() method allows JavaScript to set a custom validation error message on an input element.

This is useful when a form needs to check a condition that HTML attributes alone cannot fully describe.

How does it work?

  • Pass a non-empty string to make the field invalid.
  • The string becomes the field's custom validation message.
  • Pass an empty string to clear the custom error.
  • After clearing the error, the field can become valid again if its other constraints are satisfied.

Code example

The following example compares two password fields. If they do not match, JavaScript sets a custom error. If they match, it clears it. 

function checkPasswords() {
    if (password.value !== confirmPassword.value) {
        confirmPassword.setCustomValidity(
            'Passwords do not match.'
        );
    } else {
        confirmPassword.setCustomValidity('');
    }
}

Remember

  • setCustomValidity() creates custom validation messages.
  • A non-empty message makes the field invalid.
  • An empty string clears the custom error.
  • Recheck custom validation whenever related fields change.
  • Use checkValidity() to check the complete form before submission.

What are aria-describedby and aria-invalid?

Accessible form validation should help all users understand what a field needs and how to correct an error.

aria-describedby

The aria-describedby attribute connects an input to additional text using the ID of that text. Screen readers can use this relationship to provide instructions or error messages.

aria-invalid

The aria-invalid attribute communicates that the current value does not satisfy the field's requirements.

  • Use aria-describedby to connect help text or error messages.
  • Use aria-invalid="true" when a field has an error.
  • Use aria-invalid="false" when the field is valid.
  • Keep error messages visible and understandable.
  • Update the attributes when the field's validation state changes.

Code example

The input below is connected to its instruction and error message. JavaScript updates aria-invalid when validation fails or succeeds. 

<input
    id="student-id"
    aria-describedby="id-hint id-error"
    aria-invalid="false"
>

<p id="id-hint">
    Enter exactly 9 digits.
</p>

<p id="id-error"></p>

Remember

  • aria-describedby references the IDs of related text.
  • aria-invalid communicates whether the current value is invalid.
  • Do not rely on color alone to communicate an error.
  • Keep instructions and error messages associated with the correct field.
  • Accessible validation benefits keyboard and screen-reader users.

Semantic HTML

Semantic HTML uses elements that describe the meaning and purpose of content.

What Is Semantic HTML?

Semantic elements tell browsers and assistive technologies what different parts of a webpage represent.

Common Semantic Elements

  • <header> — introductory content
  • <nav> — navigation links
  • <main> — the main content of a page
  • <article> — independent content
  • <footer> — footer information

Why Is It Important?

Semantic HTML improves page structure and helps screen-reader users navigate content.

Example

<main>
  <h1>My Website</h1>
  <p>Welcome!</p>
</main>

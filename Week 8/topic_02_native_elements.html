WEEK 08 · WEB ACCESSIBILITY

Native Elements Over Div

Native HTML elements provide built-in meaning and useful browser behavior.

Why Use Native Elements?

Elements such as buttons and links already support expected interactions and keyboard behavior.

Use a Button for Actions

<button type="button">Save</button>

A button is suitable for actions such as submitting, opening, or saving.

Use a Link for Navigation

<a href="about.html">About</a>

A link navigates to another page or location.

Avoid Unnecessary Divs

A div is a generic container. Making it clickable does not automatically give it the keyboard behavior of a native button.

Remember

Use the element that best matches the purpose of the content.

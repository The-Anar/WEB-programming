Alt Text

Alternative text communicates useful image information to people who cannot see the image.

What Is Alt Text?

The alt attribute provides a text alternative for an image.

Informative Images

Describe the information or purpose of the image.

<img src="campus.jpg" alt="University campus in spring">

Decorative Images

If an image is purely decorative and adds no useful information, use an empty alt attribute.

<img src="decoration.png" alt="">

Common Mistakes

  • Leaving alt text missing when the image needs a text alternative.
  • Writing vague descriptions such as "picture".
  • Repeating information already provided nearby.

Remember

Write alt text according to the image's purpose and context.

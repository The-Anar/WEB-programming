WEEK 08 · WEB ACCESSIBILITY

ARIA Attributes

ARIA communicates accessibility information about elements and their states.

What Is ARIA?

ARIA stands for Accessible Rich Internet Applications. It helps assistive technologies understand interface elements.

aria-label

Provides an accessible name when a visible text label is not available.

<button aria-label="Close">×</button>

aria-expanded

Communicates whether a collapsible control is expanded.

<button aria-expanded="false">Menu</button>

aria-describedby

Connects an element to additional descriptive information.

<input aria-describedby="help">
<p id="help">Enter your email address.</p>

Important Rule

Prefer native HTML where possible. ARIA communicates information but does not automatically make an element keyboard accessible.

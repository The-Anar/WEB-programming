WEEK 08 · WEB ACCESSIBILITY

Keyboard Navigation

Users should be able to navigate and operate important website features without a mouse.

Useful Keyboard Keys

  • Tab: move to the next focusable element.
  • Shift + Tab: move to the previous focusable element.
  • Enter: activate links and buttons where appropriate.
  • Space: activate buttons and certain controls.

Visible Focus

A visible focus indicator shows users which element is currently selected.

Avoid Keyboard Traps

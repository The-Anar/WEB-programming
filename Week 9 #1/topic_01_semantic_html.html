Topic 01 — Semantic HTML

Make content understandable and operable for people using different devices and assistive technologies.

What is Semantic HTML?

Semantic HTML means using HTML elements that describe the meaning and purpose of their content. Instead of choosing elements only for their appearance, we choose elements based on what the content represents.

Semantic elements help browsers, search engines, developers, and assistive technologies understand the structure of a webpage.

Important Semantic Elements

<header>

Represents introductory content, such as a page title, logo, or heading.

<nav>

Contains important navigation links that help users move around a website.

<main>

Identifies the main content of a page. A page should normally have one main element.

<article>

Represents independent content that can make sense on its own, such as an article or post.

<section>

Groups related content together, usually with its own heading.

<footer>

Represents footer information, such as copyright details or contact information.

Why Semantic HTML Matters

  • It gives webpages a clear and meaningful structure.
  • Screen readers can identify important page regions.
  • Keyboard and assistive technology users can navigate more easily.
  • It makes HTML easier for developers to read and maintain.
  • It helps search engines understand the content of a webpage.

Semantic HTML vs. Generic Containers

A generic <div> groups content but does not communicate what that content means. Semantic elements provide additional meaning.

Generic HTML example

<div class="header">
    <h1>My Website</h1>
</div>

<div class="navigation">
    <a href="#">Home</a>
</div>

<div class="content">
    <p>Welcome to my website.</p>
</div>

Semantic HTML example

<header>
    <h1>My Website</h1>
</header>

<nav aria-label="Main navigation">
    <a href="#">Home</a>
</nav>

<main>
    <p>Welcome to my website.</p>
</main>

Both examples can look similar in a browser, but semantic elements communicate the purpose of each region.

Try It — Page Landmark Structure

The example below shows how semantic elements organize a webpage. Each region has a specific purpose.

Header

Website title and introductory information

Navigation

Links to different pages or sections

Main content — Article

Independent content that can stand on its own.

Aside

Related information that supports the main content.

Footer

Copyright or contact information

Remember

  • Choose HTML elements according to their meaning, not just their appearance.
  • Use landmarks such as header, nav, main, article, section, and footer.
  • Use headings in a logical order to organize page content.
  • Prefer native HTML elements before adding custom JavaScript or ARIA.
  • Check that the page structure is understandable with assistive technologies.

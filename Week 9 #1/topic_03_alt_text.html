Alt Text on Images

Images communicate information, but not every user can see them. Alternative text helps screen readers explain the content or purpose of an image to people who cannot see it.

01 · The concept

What Is Alt Text?

Alt text is written inside an image's alt attribute. It gives users of screen readers an accessible text alternative for an image.

Key question: What would someone miss if they couldn't see the image? 
<img src="chart.png"
     alt="Bar chart: 40% rise in enrollment 2024–2026">

Good alt text describes the content AND purpose of an informative image, rather than simply naming the file.

02 · Four image situations

When and What to Write

Informative

Describe the content

Describe the important information that the image communicates. 

<img src="chart.png"
alt="Bar chart: 40% rise in enrollment 2024–2026">

The text explains what the chart communicates.

Decorative

Use an empty alt attribute

A decorative image adds visual style but does not provide important information. 

<img src="divider.svg" alt="">

Empty alt tells screen readers to skip the image completely.

Functional

Describe the action

When an image is used inside a button, describe what the button does, not how the icon looks. 

<button>
  <img src="search.svg" alt="Search">
</button>

The screen reader can announce the action: Search.

Incorrect example

Avoid useless alt text

✦

Do not write redundant descriptions that do not explain the image's actual content or purpose. 

<img src="logo.png"
alt="image of a logo">

"Image of" is unnecessary because screen readers already announce that it is an image.

03 · Important rules

Remember These Differences

Informative: Describe the content and purpose of the image.
Decorative: Use alt="" so screen readers skip it.
Functional: Describe the action, such as alt="Search", not the appearance.
Never write: "Image of..." or "Photo of..." because this is redundant.

Empty alt vs. missing alt

Correct for decorative images 
<img src="divider.svg" alt="">

Screen readers skip this image completely.

Incorrect 
<img src="background_swirl.jpg">

With no alt attribute, screen readers may announce the raw filename.

06 · Summary

What We Learned

  • Informative images: Describe the content and purpose.
  • Decorative images: Use alt="".
  • Functional images: Describe the action, not the appearance.
  • Missing alt: Screen readers may announce the raw filename.
  • Redundant wording: Avoid "image of" and "photo of".
Main takeaway: Write alt text based on what users need to understand, not simply what an image looks like.

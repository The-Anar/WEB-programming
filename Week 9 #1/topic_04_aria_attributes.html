ARIA Roles & Attributes

ARIA provides additional information about elements for assistive technologies. It helps communicate names, descriptions, roles, and states to screen reader users.

01 · Introduction

When HTML Is Not Enough

Semantic HTML already provides meaning to many elements. Sometimes, however, additional accessibility information is needed. ARIA attributes can provide that information.

First rule: Use semantic HTML before ARIA. ARIA should add, never replace. 
<!-- Use semantic HTML first -->
<nav aria-label="Main navigation">
    <a href="index.html">Home</a>
</nav>
02 · Important ARIA attributes

Five Attributes to Understand

aria-label

Give an element a name

Provides a visible or hidden accessible name when an element does not have a suitable text label. 

<nav aria-label="Main navigation">
    ...
</nav>

A screen reader can identify this navigation region as Main navigation.

aria-describedby

Connect a longer description

Links an element to another element containing additional information, such as a hint or error message. 

<input
    type="text"
    aria-describedby="help-text">

<p id="help-text">
    Enter your university email.
</p>

The input is associated with its longer description.

aria-hidden="true"

Hide content from screen readers

Removes an element from the accessibility tree. It does not make the element visually disappear. 

<span aria-hidden="true">★</span>
<span>Rated 4.8 out of 5</span>

The decorative star is hidden from screen readers, while the rating text remains available.

aria-expanded

Communicate open or closed state

Announces whether a collapsible interface element, such as a menu or accordion, is expanded. 

<button
    aria-expanded="false"
    aria-controls="menu">
    Menu
</button>

<ul id="menu" hidden>
    ...
</ul>

The value changes when the menu opens or closes.

role

Assign a semantic role

Assigns or overrides an element's semantic role when an appropriate native element is not available. 

<div role="button"
     tabindex="0">
    Open project
</div>

This gives the element a button role, but keyboard interaction must also be implemented.

06 · Summary

What We Learned

  • aria-label: Gives an element an accessible name.
  • aria-describedby: Connects an element to a longer description.
  • aria-hidden="true": Hides an element from screen readers, not visually.
  • aria-expanded: Communicates whether a collapsible element is open or closed.
  • role: Assigns or overrides an element's semantic role.
Main takeaway: Use semantic HTML first. ARIA should add accessibility information, not replace the meaning already provided by HTML.

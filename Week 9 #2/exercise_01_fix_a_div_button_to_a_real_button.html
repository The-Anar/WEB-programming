01 · THE PROBLEM

Why a div Is Not a Real Button

A div is a general-purpose container. Even if we add a click event, it does not automatically support keyboard interaction or announce itself as a button to screen readers. 

<div onclick="submitForm()">
  Submit form
</div>

This is not a good replacement for a real button. It requires extra keyboard and accessibility code.

02 · FIXED VERSION

Real Submit and Close Buttons

Press Tab to focus the buttons. Press Enter or Space to activate the focused button. You can also click them.

Try the Submit or Close button.

03 · ACCESSIBILITY

Why These Buttons Work

  • Keyboard support: Both buttons can be reached using Tab.
  • Enter and Space: Both keys activate a native button.
  • Screen readers: The elements are announced as buttons.
  • Accessible name: The Close button uses aria-label="Close".
  • Focus indicator: A visible outline shows which button is focused.

04 · KEY CONCEPT

Use the Correct HTML Element

Use a button when the user performs an action.

<button type="button">
  Submit form
</button>

<button type="button" aria-label="Close">
  ✕
</button>

Use a link when the user navigates to another page.

<a href="about.html">
  About
</a>

Native HTML elements already provide important accessibility features. Use them whenever possible.

Add Proper Alt Text

Learn how to write alternative text for informational, decorative, linked, and complex images.

INTRODUCTION

What Is Alt Text?

Alt text is a written description added to an image using the HTML alt attribute.

Screen readers can read this text aloud so people who cannot see an image can understand its purpose or information. 

<img src="photo.jpg"
     alt="Description of the image">

IMAGE 01 · INFORMATIONAL

Campus Building Photo

This image provides information about the university. Its alt text should describe what is visible.

Correct alt text

alt="Gachon University main building, a modern glass structure surrounded by trees"

IMAGE 02 · DECORATIVE

Decorative Wavy Divider

Decorative images do not communicate important information. Screen readers should skip them.

Correct HTML

<img src="wave-divider.svg" alt="">

An empty alt attribute tells assistive technology that this image is decorative.

IMAGE 03 · INSIDE A LINK

University Logo

When an image is inside a link, its alt text should explain the link's destination or purpose.

Correct alt text

alt="Gachon University — go to homepage"

The image link should communicate where the user will go when they activate it.

IMAGE 04 · DATA CHART

Student Enrollment Chart

Charts contain important information. The alternative text should communicate the main data.

Correct alt text

alt="Bar chart of student enrollment: 2024: 1,200; 2025: 1,400; 2026: 1,476"

KEY POINTS

What We Learned

  • Informational images need meaningful descriptions.
  • Decorative images should use alt="".
  • Linked images should describe the link's purpose.
  • Charts should communicate important data.
  • Every informative image needs appropriate alternative text.

THREE CONFORMANCE LEVELS

Understanding A, AA, and AAA

WCAG uses three levels to describe how well a website meets accessibility requirements.

A

Level A

Minimum — Required

Basic accessibility requirements. Without these, some users may be unable to access important content or functionality.

Examples: image alternatives, keyboard access, and labels for form controls.

AA

Level AA

Standard — Recommended target

A widely used accessibility target that addresses common barriers for users with different disabilities.

Examples: sufficient color contrast, text resizing, and visible keyboard focus.

AAA

Level AAA

Enhanced — Highest level

More demanding accessibility requirements that provide additional support in specific situations.

Examples: enhanced contrast and sign-language interpretation for prerecorded video.

THE FOUR PRINCIPLES

POUR — The Foundation of WCAG

Accessible websites should follow four important principles.

01 · PerceivableUsers must be able to perceive information through sight, hearing, or assistive alternatives.
02 · OperableUsers must be able to operate controls and navigate the website.
03 · UnderstandableInformation and website operation must be clear and predictable.
04 · RobustContent must work reliably with browsers and assistive technologies.

CURRENT WEB STANDARD

WCAG 2.2

WCAG 2.2 is the latest published W3C Web Content Accessibility Guidelines Recommendation. It builds on WCAG 2.1 and adds new success criteria, including requirements related to focus appearance, dragging movements, and target size.

Remember: WCAG 2.2 includes the earlier WCAG 2.1 requirements, with additional criteria.

KEY POINTS

What We Learned

  • Level A covers minimum accessibility requirements.
  • Level AA is a common target for accessible websites.
  • Level AAA provides enhanced accessibility requirements.
  • POUR stands for Perceivable, Operable, Understandable, and Robust.
  • WCAG 2.2 is the latest published W3C Recommendation.

WEEK 9.2 · TOPIC 03

Semantic HTML

Semantic HTML uses meaningful elements to describe the structure and purpose of webpage content. It helps browsers, developers, and assistive technologies understand a page.

BATSUREN ANAR · STUDENT ID: 202637018

THE PROBLEM

Div Soup — Too Many Generic Elements

A page built entirely with generic div elements does not clearly describe what each part of the page represents.

✗ Non-semantic HTML
<div id="header">
  <div id="logo">My Site</div>
  <div id="nav">
    <div class="link">Home</div>
  </div>
</div>

<div id="main">
  <div class="title">Hello</div>
</div>

<div id="footer">© 2026</div>

The browser sees generic containers. Their meaning is not automatically communicated to assistive technology.

THE SOLUTION

Use Semantic Elements

✓ Semantic HTML
<header>
  <a href="/">My Site</a>

  <nav aria-label="Main navigation">
    <a href="/">Home</a>
  </nav>
</header>

<main>
  <article>
    <h1>Hello</h1>
  </article>
</main>

<footer>© 2026</footer>

These elements communicate the purpose of different page regions. Screen-reader users can use landmarks to move around the page.

VISUAL STRUCTURE

How Semantic Elements Organize a Page

<header> — Website heading and introduction
<nav> — Home About
<main> — Main page content
<article> — Independent article

SCREEN READER LANDMARKS

What Assistive Technology Can Understand

HTML elementPurpose or announcement
<header>Banner landmark when used as the page header.
<nav>Navigation landmark for important navigation links.
<main>Main landmark containing the primary page content.
<article>Independent, self-contained content.
<aside>Complementary content related to the main content.
<footer>Content information for its relevant section or page.
<section>A thematic group of content, often with a heading.
<h1>–<h6>Heading levels that organize the content hierarchy.

HEADING HIERARCHY

Organize Content with Headings

✓ Good heading order

<h1>Main page title</h1>
  <h2>First section</h2>
    <h3>Subsection</h3>
  <h2>Second section</h2>

The hierarchy makes the page easier to navigate.

✗ Poor heading order

<h1>Main page title</h1>
  <h4>First section</h4>
    <h2>Subsection</h2>
  <h6>Second section</h6>

Skipping levels can make the structure confusing.

Use CSS to change the visual size of headings. Do not choose heading levels just because they look the right size.

KEY POINTS

What We Learned

  • Semantic HTML describes the purpose of webpage elements.
  • Use one primary <main> landmark per page.
  • Use headings in a logical hierarchy.
  • Use <nav> for navigation and <article> for independent content.
  • Semantic elements help screen-reader users navigate websites.

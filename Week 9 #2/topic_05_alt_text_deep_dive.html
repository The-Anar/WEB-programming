Alt Text Deep Dive

Alternative text describes the purpose or information of an image to people who cannot see it. Good alt text depends on the context in which the image is used.

BATSUREN ANAR · STUDENT ID: 202637018

THE BASIC RULE

Every Image Needs an Alt Attribute

The alt attribute provides a text alternative for an image. Screen readers can announce this text to users who cannot see the image. 

<img src="campus.jpg" alt="Gachon University campus">

An image without an alt attribute may cause a screen reader to announce its filename or image URL instead.

FOUR IMAGE TYPES

Choose the Correct Alt Text

01. Decorative Images

These images do not add important information. They are only used for decoration.

✓ Correct
<img src="decoration.png" alt="">

An empty alt tells screen readers to ignore the decorative image.

02. Images Inside Links

Describe the destination or action of the link, not just the appearance of the image.

✓ Correct
<a href="courses.html">
  <img src="book.png"
       alt="Browse our courses">
</a>

The alt text communicates what happens when the user activates the link.

03. Informational Images

Describe the important information that the image communicates.

✓ Correct
<img src="chart.png"
     alt="Sales increased from 50
     to 80 between January and June">

Focus on the meaning of the image, not every visual detail.

04. Images Containing Text

If an image contains important words, provide those words in the alternative text.

✓ Correct
<img src="announcement.png"
     alt="Registration closes
     on December 15">

Whenever possible, use real HTML text instead of putting important text inside an image.

DECISION TREE

How Should You Describe an Image?

Question 1: Is the image purely decorative?

Yes → Use alt="".

Question 2: Is the image the only content inside a link?

Yes → Describe the link's destination or action.

Question 3: Does the image communicate information?

Yes → Describe its important information.

Question 4: Does the image contain important text?

Yes → Include the text in the alternative description, or use real HTML text.

COMMON MISTAKES

Bad vs Good Alt Text

Bad exampleWhy it is badBetter example
alt="image" Does not explain anything. alt="Student reading a book"
alt="IMG_2045.jpg" Uses a filename instead of a description. alt="University library interior"
alt="picture of a chart" Does not explain the chart's information. alt="Website visits increased in June"
Missing alt attribute Provides no text alternative. alt="Gachon University logo"

COMPLEX IMAGES

Charts and Detailed Diagrams

Sometimes a short alt description is not enough to explain a complex chart, graph, map, or diagram.

Use a short alt description and provide the full explanation nearby.

<figure>
  <img src="results.png"
       alt="Bar chart comparing sales over six months"
       aria-describedby="chart-description">

  <figcaption id="chart-description">
    Sales increased steadily from January
    through June, reaching the highest value
    in June.
  </figcaption>
</figure>

The short alt identifies the image. The longer description provides the details that a user needs to understand it.

KEY POINTS

What We Learned

  • Every image needs an alt attribute.
  • Decorative images should use an empty alt attribute: alt="".
  • Images inside links should describe the link destination or action.
  • Informational images should communicate their important meaning.
  • Important text inside images should also be available as text.
  • Complex charts may need a longer description.
  • Good alt text depends on the image's context and purpose.

ARIA Attributes

ARIA stands for Accessible Rich Internet Applications. It provides additional information to assistive technologies when standard HTML alone is not enough.

BATSUREN ANAR · STUDENT ID: 202637018

INTRODUCTION

What Is ARIA?

ARIA adds accessibility information to HTML elements. It helps screen readers understand the names, roles, states, and relationships of interactive elements. 

<button aria-label="Close menu">
  ×
</button>

The visual symbol is ×, but the accessible name tells a screen reader that the button closes the menu.

IMPORTANT ATTRIBUTES

Six Common ARIA Attributes

01. aria-label

Provides an accessible name when visible text does not provide a suitable one.

<button aria-label="Close menu">
  ×
</button>

A screen reader can announce: "Close menu, button."

02. aria-describedby

Connects an element to additional descriptive information.

<input
  type="password"
  aria-describedby="password-help">

<p id="password-help">
  Use at least 8 characters.
</p>

The description gives the user extra guidance.

03. aria-hidden

Removes an element and its contents from the accessibility tree.

<span aria-hidden="true">
  ★
</span>

Useful for decorative icons that do not need to be announced.

04. aria-live

Allows screen readers to announce content that changes dynamically.

<div aria-live="polite">
  Your message was saved.
</div>

The update can be announced without moving keyboard focus.

05. aria-expanded

Communicates whether an interactive section is expanded or collapsed.

<button aria-expanded="false">
  Show details
</button>

Update the value whenever the section opens or closes.

06. role

Identifies the purpose of an element when a suitable native HTML element is unavailable.

<div role="status">
  Upload complete.
</div>

Use native HTML elements whenever they already provide the correct semantics.

IMPORTANT RULE

The First Rule of ARIA

Do not use ARIA when native HTML already works.

Native HTML elements already include many accessibility features. Adding unnecessary ARIA can create confusing or incorrect information for assistive technologies.

✗ Less preferred

<div
  role="button"
  tabindex="0">
  Submit
</div>

✓ Preferred

<button type="button">
  Submit
</button>

✗ Less preferred

<div>Email address</div>
<input aria-label="Email">

✓ Preferred

<label for="email">
  Email address
</label>
<input id="email">

KEY POINTS

What We Learned

  • aria-label provides an accessible name.
  • aria-describedby connects additional descriptions.
  • aria-hidden hides content from assistive technologies.
  • aria-live announces dynamic content updates.
  • aria-expanded communicates expanded or collapsed states.
  • role identifies an element's purpose.
  • Prefer native HTML over unnecessary ARIA.

Keyboard Navigation

A website should be usable without a mouse. Keyboard navigation allows people to move through interactive elements using keys such as Tab, Enter, Space, and the arrow keys.

KEYBOARD SHORTCUTS

Important Keyboard Keys

KeyFunction
TabMoves keyboard focus to the next interactive element.
Shift + TabMoves keyboard focus to the previous interactive element.
EnterActivates buttons and follows links.
SpaceActivates buttons and toggles checkboxes.
Arrow keysMove within certain widgets, menus, and radio groups.
EscapeOften closes dialogs, menus, and popups.

FOCUS INDICATORS

Why Visible Focus Matters

A focus indicator shows which element currently receives keyboard input. Without it, users may not know where they are on the page.

✓ Recommended CSS

button:focus-visible,
a:focus-visible,
input:focus-visible {
  outline: 3px solid #B7A2FF;
  outline-offset: 4px;
}

The outline makes the focused element easier to identify. Do not remove focus indicators unless you provide an equally visible alternative.

TABINDEX

Understanding tabindex

tabindex="0"

Adds an element to the normal keyboard Tab order.

<div tabindex="0">
  Keyboard focusable
</div>

tabindex="-1"

Allows an element to receive programmatic focus, but does not add it to the normal Tab order.

<h2 id="heading" tabindex="-1">
  Section heading
</h2>

Avoid positive tabindex values

<button tabindex="5">Button</button>

Positive values such as 1, 2, or 5 create a custom focus order that can become confusing. Prefer the natural document order.

SKIP LINKS

Skip to Main Content

A skip link lets keyboard users bypass repeated navigation and jump directly to the main content. 

<a href="#main-content" class="skip">
  Skip to main content
</a>

<main id="main-content">
  Main page content
</main>

The link is usually hidden until it receives keyboard focus. It supports WCAG 2.4.1, Bypass Blocks.

KEY POINTS

What We Learned

  • Websites should work without a mouse.
  • Tab moves forward through interactive elements.
  • Shift + Tab moves backward.
  • Enter and Space activate controls according to their behavior.
  • Arrow keys work within certain widgets.
  • Visible focus indicators help users track their position.
  • tabindex="0" adds an element to normal keyboard navigation.
  • tabindex="-1" allows programmatic focus.
  • Skip links help users bypass repeated navigation.

01. Introduction — Lighthouse Performance Audit

Lighthouse is a tool that measures website quality, including performance, accessibility, best practices, and SEO. Its Performance score helps identify opportunities to improve page loading and responsiveness.

For this exercise, I tested my own Web Programming portfolio before and after making performance improvements. I focused on reducing unnecessary JavaScript loading and improving how the Music Corner loads its YouTube player.

03. Problems and Opportunities

1. Unnecessary YouTube Loading

The Music Corner's YouTube iframe could load even when the music panel was not being used. This creates unnecessary network requests.

2. JavaScript Loading Behavior

A normal script can block HTML parsing while the browser downloads and executes JavaScript. Using defer avoids this blocking behavior.

3. Duplicate CSS

The stylesheet contained a repeated prefers-reduced-motion media query. Keeping one copy makes the stylesheet cleaner.

04. Three Optimizations Applied

Optimization 1 — Add defer to JavaScript

I added the defer attribute to the external music-player script. The browser can continue parsing HTML while the JavaScript downloads. The script executes after HTML parsing is complete.

Before

<script src="music-player.js"></script>

After

<script src="music-player.js" defer></script>

Optimization 2 — Load the YouTube iframe on demand

Instead of loading the YouTube player immediately, I changed the Music Corner so the iframe is created only when the user opens the music panel. This avoids loading an external video player when it is not needed.

Before

// The YouTube iframe was initialized
// during the initial page setup.

After

// The YouTube iframe is created
// when the Music Corner is opened.

Optimization 3 — Remove duplicate CSS

I removed the repeated reduced-motion media query while keeping the existing accessibility behavior. This avoids unnecessary duplicate CSS rules.

Before

/* Repeated reduced-motion CSS block */
@media (prefers-reduced-motion: reduce) {
    /* motion settings */
}

/* Another duplicate block */

After

/* Keep one reduced-motion CSS block */
@media (prefers-reduced-motion: reduce) {
    /* motion settings */
}

06. Reflection — What I Learned

The most useful change was delaying the YouTube iframe until the Music Corner was opened. External video players can require additional network requests and resources, so loading them only when needed avoids unnecessary work during the initial page load.

Adding defer also improves script loading behavior because JavaScript can download while the browser continues parsing the HTML document. Removing duplicate CSS makes the stylesheet cleaner and easier to maintain.

My Performance score was already 100 before the changes, so it remained 100 afterward. However, my Speed Index improved from 1.8 seconds to 1.5 seconds. This exercise taught me that performance optimization is not only about increasing a score, but also about avoiding unnecessary work and improving how a website loads for users.

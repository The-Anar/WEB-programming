Measuring Performance

Use Chrome DevTools to inspect network requests, identify large files, understand request statuses, and read the Waterfall timeline.

BATSUREN ANAR · STUDENT ID: 202637018

CHROME DEVTOOLS

Network Tab in DevTools

The Network tab shows the resources and requests that the browser loads when a webpage opens.

How to open the Network tab

Open your webpage in Chrome. Press F12 to open Developer Tools, select the Network tab, and reload the page to record its network requests.

INSPECT THE REQUESTS

Five Things to Look For

01

Large files

Look for large files, especially images over 200 KB. Sort by the Size column to find files that use more data.

02

Blocking requests at the top

CSS and JavaScript requests can block or delay rendering. Inspect requests that may prevent the page from displaying quickly.

03

Long chains of serial requests

Look for requests that happen one after another. Each request may wait for the previous request to finish.

04

304 Not Modified

A 304 response means the browser can reuse its cached resource instead of downloading the same content again.

05

Duplicate requests

Check whether the same file is being loaded more than once. Duplicate requests may cause unnecessary network activity.

Tip: Sort the Size column to find large resources, then inspect their request details and timing.

REQUEST STATUS

Understanding Network Status Codes

Status Meaning What it indicates
200 OK The request succeeded.
304 Not Modified The browser can reuse its cached resource.
404 Not Found The requested resource could not be found.
500 Internal Server Error The server encountered an error.
Remember: A 304 response is not an error. It indicates that the browser can use a cached version of the resource.

KEY TAKEAWAYS

Remember

  • Use F12 to open Chrome DevTools.
  • The Network tab records the requests made by a webpage.
  • Sort by Size to find large files, including images over 200 KB.
  • Check for blocking requests and long serial request chains.
  • 304 Not Modified means a cached resource can be reused.
  • The Waterfall displays the timeline of network requests.
  • Size, Time, Initiator and Status help explain each request.

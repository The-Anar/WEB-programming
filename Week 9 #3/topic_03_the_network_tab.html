The Network Tab

Use Chrome DevTools to inspect network requests, identify large files, find loading delays, and understand how a webpage loads its resources.

BATSUREN ANAR · STUDENT ID: 202637018

GETTING STARTED

What Is the Network Tab?

See what happens when a page loads

The Network tab in Chrome DevTools shows the resources a browser requests when loading a webpage. These can include HTML, CSS, JavaScript, images, fonts, and other files.

It helps developers understand which requests take time, which files are large, and whether resources are being loaded more than once.

OPEN DEVTOOLS

How to Open the Network Tab

1

Open DevTools

Press F12 on your keyboard, or right-click the webpage and select Inspect.

2

Select Network

Find the Network tab in the DevTools panel. It displays the requests made by the browser.

3

Reload the page

Reload the webpage while the Network tab is open to capture its loading requests.

4

Inspect the requests

Look at file sizes, loading times, request status, and the order in which files load.

Lecture instruction: Open F12, select Network, and reload the page.

WHAT TO LOOK FOR

Five Things to Check

1

Large files

Look for large files, especially images over 200 KB. Sort by the Size column to find them more easily.

2

Blocking requests

Check requests near the top that may block rendering, such as CSS or JavaScript files.

3

Long request chains

Look for long chains of serial requests. Each request may wait for the previous request to finish.

4

304 Not Modified

A 304 response indicates that a cached resource can be reused instead of sending the full resource again.

5

Duplicate requests

Check whether the same file is being requested more than once unnecessarily.

UNDERSTANDING THE WATERFALL

Reading the Waterfall

What is a waterfall timeline?

The Network waterfall is a visual timeline of requests made by the browser. It helps show when requests start and how long they take.

Timeline

Shows when each network request happens and how long it takes.

Size

Shows the resource size, including compressed and original bytes.

Time

Shows how long a request took to complete.

Initiator

Shows what triggered the request, such as an HTML element or JavaScript file.

Status

Shows the response status, such as 200, 304, 404, or 500.

REQUEST STATUS

Common Status Codes

Status Meaning What it tells you
200 OK The request succeeded.
304 Not Modified A cached version can be reused.
404 Not Found The requested resource could not be found.
500 Internal Server Error The server encountered an error.

KEY TAKEAWAYS

Remember

  • Open DevTools with F12 and select Network.
  • Reload the page to capture network requests.
  • Look for large files, blocking requests, and long request chains.
  • A 304 response means a cached resource can be reused.
  • The waterfall helps you understand request timing.
  • Check file size, time, initiator, and status.

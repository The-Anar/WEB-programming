Performance · Topic 04

Image Optimization

Images are often some of the largest resources on a webpage. Choosing the right format, compressing files, and serving images at the correct dimensions can improve loading speed.

BATSUREN ANAR · STUDENT ID: 202637018

THE BIGGEST WIN

Why Optimize Images?

Images can make webpages unnecessarily heavy

Large image files take longer to download and can slow down a webpage. Optimizing images reduces unnecessary file size while keeping the visual quality suitable for the page.

The lecture identifies image optimization as one of the biggest opportunities for improving website performance.

IMAGE FORMATS

Choose the Right Format

Different image formats are designed for different uses.

Format Best use File size / benefit When to use
JPEG Photos and complex images Small files for photographs Use for photographs
PNG Transparency and logos Lossless, but often larger When transparency is needed
WebP Photos and transparency 25–35% smaller than JPEG/PNG in the slide Modern browsers
SVG Icons, logos, and charts Scalable vector graphics When crisp vector art is needed

FORMAT DETAILS

Understanding Each Format

JPEG

Photographs

JPEG is commonly used for photographs and complex images. It is a good choice when you want relatively small photo files.

PNG

Transparency and Logos

PNG supports transparency and lossless image quality. It can produce larger files, so use it when its features are needed.

WebP

Modern Web Images

WebP supports photographs and transparency. The lecture states it can save 25–35% compared with JPEG or PNG.

SVG

Vector Graphics

SVG is suitable for icons, logos, and charts. It can scale to different sizes while staying crisp because it is vector-based.

IMPORTANT RULE

Use the Displayed Image Size

Serve images at the size they are displayed

Do not upload an unnecessarily huge original camera image when the webpage only displays it at a much smaller size. Prepare an image with dimensions appropriate for its actual display size.

Example: If a webpage displays a photo at 600 pixels wide, avoid serving a massive original image that is thousands of pixels wide when those extra dimensions are not needed.

KEY TAKEAWAYS

Remember

  • JPEG is suitable for photographs.
  • PNG is useful when transparency is needed.
  • WebP supports photos and transparency with smaller file sizes.
  • SVG is useful for scalable icons, logos, and charts.
  • Use Squoosh or TinyPNG to compress images.
  • Serve images at the size they are displayed, not their original camera size.

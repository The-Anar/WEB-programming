Lazy Loading

Load images and other resources only when they are needed. Improve initial page loading speed by avoiding unnecessary downloads.

K0126002 · Gachon University · 2026 Fall · Dr. Toshpulatov

What Is Lazy Loading?

Lazy loading is a performance technique that delays loading non-essential resources until they are close to becoming visible on the user's screen.

For example, imagine a webpage containing 30 images. Without lazy loading, the browser may start downloading all 30 images immediately, even though the user can only see the first few.

Key idea: Load important content first. Load content farther down the page only when the user gets close to it.

Why Use Lazy Loading?

Faster Initial Loading

The browser has fewer resources to download when the page first opens.

Less Data Usage

Users do not need to download images they never scroll down to see.

Better Performance

Reducing unnecessary downloads can help the page become usable sooner.

Useful for Long Pages

Image galleries, product lists, and articles can contain many resources below the first screen.

How to Use loading="lazy"

HTML provides a built-in loading attribute for images. Set it to lazy to tell the browser to delay loading an image until it approaches the viewport.

Without Lazy Loading

<img src="gallery-photo.jpg" alt="Mountain landscape">

With Lazy Loading

<img src="gallery-photo.jpg" alt="Mountain landscape" loading="lazy" >

The browser decides when to download the image based on how close it is to the visible area of the page.

Lazy vs. Eager Loading

loading="lazy"

Delays loading until the image is near the viewport.

  • Useful for images below the fold
  • Reduces unnecessary initial downloads
  • Good for long pages and galleries

loading="eager"

Allows the image to load immediately without lazy-loading behavior.

  • Useful for important visible images
  • Appropriate for above-the-fold content
  • Can help prioritize the main page image
<!-- Load immediately --> <img src="hero.jpg" alt="Main banner" loading="eager"> <!-- Load when needed --> <img src="photo-2.jpg" alt="Gallery photo" loading="lazy">

Important Rule: Never Lazy-Load the Hero Image

The hero image is usually the large, important image visible near the top of a webpage. It should normally load immediately.

Lazy-loading an important above-the-fold image can delay its appearance and make the page feel slower.

Best practice: Use loading="eager" for important images visible immediately. Use loading="lazy" for images farther down the page.
<!-- Important hero image --> <img src="hero.jpg" alt="Website hero" loading="eager" width="1200" height="600"> <!-- Image lower on the page --> <img src="gallery.jpg" alt="Gallery photograph" loading="lazy" width="800" height="500">

Prevent Layout Shifts with Width and Height

When an image loads without reserved dimensions, the browser may not know how much space to leave for it. The page can move when the image finally appears.

This movement is called Cumulative Layout Shift (CLS). Setting image dimensions helps the browser reserve the correct space before the image loads.

Without Dimensions

The browser may not reserve enough space. Content can shift after the image appears.

With Dimensions

The browser can calculate the image's aspect ratio and reserve its space in advance.

<img src="photo.jpg" alt="A landscape" loading="lazy" width="800" height="500" >

When Should You Use Lazy Loading?

  • Image galleries with many photographs.
  • Long articles with images below the first screen.
  • Product pages with many product images.
  • Pages where users need to scroll to see additional content.

When Should You Avoid It?

  • Important hero images at the top of the page.
  • Images immediately visible when the page opens.
  • Resources that must be available immediately.

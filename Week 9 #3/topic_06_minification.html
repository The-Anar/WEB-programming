Minification and Defer

Reduce the size of website files and prevent JavaScript from blocking the initial page rendering.

K0126002 · Gachon University · 2026 Fall · Dr. Toshpulatov

What Is Minification?

Minification is the process of removing unnecessary characters from HTML, CSS, and JavaScript files without changing how the code works.

It removes extra spaces, line breaks, comments, and sometimes shortens variable and function names.

Key idea: Smaller files usually take less time to download, helping improve website loading performance.

Before and After Minification

Before

function calculateTotal(price, tax) { // Calculate the final price const total = price + (price * tax); return total; }

Readable code with spaces, comments, and multiple lines.

After

function calculateTotal(a,b){return a+a*b}

Compact code with unnecessary characters removed.

Both versions perform the same calculation. The minified version is smaller, but it is harder for developers to read.

How Much Can Minification Save?

In the lecture example, a file was reduced from 3.2 KB to 0.6 KB.

What Is the defer Attribute?

By default, when a browser encounters a regular external JavaScript script, it may pause HTML parsing while the script downloads and executes.

The defer attribute changes this behavior. The browser downloads the script while continuing to parse the HTML, then executes the script after HTML parsing finishes.

Without defer

<script src="app.js"></script>

With defer

<script src="app.js" defer></script>
Remember: Deferred scripts execute after HTML parsing is complete and before the DOMContentLoaded event.

Normal Script vs. Defer

Normal Script

  1. Browser encounters the script.
  2. HTML parsing pauses.
  3. Script downloads and executes.
  4. HTML parsing continues.

Script with Defer

  1. Browser encounters the script.
  2. Script downloads in parallel.
  3. HTML parsing continues.
  4. Script executes after parsing finishes.

When Should You Use defer?

  • When an external script is not needed to build the initial HTML.
  • When a script needs to access HTML elements after parsing.
  • When you want to avoid blocking HTML parsing during script downloads.

Important Details

  • defer works with external scripts using the src attribute.
  • Deferred scripts execute in document order.
  • They execute after HTML parsing is complete.
  • For inline scripts, the defer attribute has no effect.
<head> <script src="first.js" defer></script> <script src="second.js" defer></script> </head>

In this example, first.js executes before second.js after the HTML document has been parsed.

Minification + Defer: Better Performance

Minification and defer solve different performance problems. They can also be used together.

Minification

Reduces the size of HTML, CSS, and JavaScript files so they can be downloaded more efficiently.

Defer

Allows the browser to continue parsing HTML while an external JavaScript file downloads.

Use minification to reduce file size and defer to prevent unnecessary JavaScript blocking during HTML parsing.

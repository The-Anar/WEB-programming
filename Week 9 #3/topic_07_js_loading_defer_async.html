JS Loading: Defer & Async

Learn how browsers load JavaScript and how the defer and async attributes prevent unnecessary delays during HTML parsing.

K0126002 · Gachon University · 2026 Fall · Dr. Toshpulatov

JavaScript Loading

When a browser encounters a JavaScript file, the way it loads and executes that file can affect how quickly the webpage becomes available.

There are three common ways to load an external JavaScript script: normal loading, async, and defer.

Key idea: Normal scripts can block HTML parsing. The async and defer attributes allow scripts to download while HTML parsing continues.

1. Normal Script — No Attribute

No attribute

When the browser encounters a normal script, HTML parsing stops. The browser downloads the JavaScript file, executes it, and then resumes parsing the HTML.

Run
<!-- Blocks HTML parsing --> <script src="app.js"></script>

The browser cannot continue parsing the document until the script has downloaded and executed.

2. Async — Download and Run Immediately

async

The async attribute allows the browser to download the JavaScript file while HTML parsing continues.

As soon as the file finishes downloading, the browser pauses HTML parsing to execute it. The execution order is not guaranteed.

HTML parsing
Parsing
Pause
Continue
Script
Download
Run
Done
<!-- Independent script, such as analytics --> <script src="analytics.js" async></script>
Important: Async scripts execute as soon as they are ready. Their execution order is not guaranteed.

3. Defer — Download Without Blocking

defer

The defer attribute allows the browser to download JavaScript while HTML parsing continues.

The script executes only after the HTML document has been fully parsed. Deferred scripts execute in their document order.

<!-- Deferred script --> <script src="app.js" defer></script>
Best default: Use defer for scripts that need the DOM. It downloads without blocking HTML parsing and preserves script order.

Compare the Three Methods

Normal

HTML parsing stops while the script downloads and executes.

Order follows the document.

Async

Downloads during parsing, then executes as soon as it is ready.

Execution order is not guaranteed.

Defer

Downloads during parsing, then executes after HTML parsing finishes.

Execution order is preserved.

HTML Examples

Normal Script

<!-- ✗ Blocks parsing --> <script src="app.js"></script>

Defer Script

<!-- ✓ For scripts that use the DOM. Order is kept. --> <script src="app.js" defer></script>

Async Script

<!-- ✓ For independent scripts like analytics --> <script src="analytics.js" async></script>

Key Points

  • Use defer by default. It is a good choice for scripts that need the DOM.
  • Use async for independent scripts. It is suitable for scripts that do not depend on other scripts or a specific execution order.
  • Both work with external scripts. The script must use the src attribute.
  • Inline scripts: For inline scripts that need the page to be parsed, use DOMContentLoaded.
  • Defer in the head: Deferred scripts can safely be placed inside the <head> section.
Remember: defer preserves execution order, while async does not guarantee it.

CDN

Content Delivery Network — deliver website resources from servers closer to users around the world.

01 — What Is a CDN?

A CDN (Content Delivery Network) is a distributed network of servers located in different geographical areas.

Instead of every user downloading files from one central server, a CDN can deliver cached content from an edge node closer to the user's location.

This reduces the distance data must travel and helps websites load faster for users around the world.

02 — Without a CDN vs With a CDN

Imagine a user in New York visiting a website whose main server is located in Seoul.

✗ Without a CDN

User in New York
↓
Server in Seoul
~11,000 km Distance between the user and server
~200 ms Per round trip (approximate)

✓ With a CDN

User in New York
↓
Edge node in New York
A few km Shorter distance to the nearby edge node
A few ms Per round trip (approximate)
Main idea: A nearby CDN edge node can serve cached content without requiring every request to travel all the way to the original server.

04 — Key Benefits of a CDN

Lower Latency

Users receive content from servers closer to their geographical location.

Faster Loading

Shorter network distances can reduce waiting time when loading website resources.

Compression

CDNs usually add compression methods such as gzip and Brotli to reduce transferred data.

Caching

Frequently requested resources can be stored and reused by nearby edge servers.

05 — Key Points

  • A CDN lowers latency for users far from the original server.
  • It delivers content through geographically distributed edge nodes.
  • CDNs usually provide compression using gzip or Brotli.
  • CDNs also provide caching to reduce repeated downloads from the original server.
  • GitHub Pages already uses a CDN to serve course websites.
